# ตัวอย่าง 03: ข้อความ LINE ขอให้เพื่อนร่วมงานเข้ากะแทน

- **บริบท:** พนักงานร้านค้า (ผู้ชาย) ให้ AI ช่วยพิมพ์ข้อความ LINE ขอให้รุ่นพี่ที่ทำงานด้วยกันทุกวันเข้ากะแทน ข้อความที่ได้สุภาพเกินจนดูเหมือนจดหมาย
- **ระดับภาษา:** `chat`
- **โหมด:** `rewrite`

## ก่อน

```text
สวัสดีครับพี่เมย์ ผมหวังว่าพี่จะสบายดีนะครับ ผมต้องการที่จะขอความช่วยเหลือจากพี่ในเรื่องหนึ่งครับ เนื่องจากในวันเสาร์ที่ 7 นี้ ผมมีความจำเป็นต้องเดินทางกลับต่างจังหวัดเพื่อไปร่วมงานบวชของน้องชาย ดังนั้น ผมจึงอยากสอบถามว่าพี่จะสามารถช่วยเข้ากะแทนผมในช่วงเวลา 13.00–21.00 น. ได้หรือไม่ครับ ทั้งนี้ ผมยินดีที่จะเข้ากะแทนพี่ในวันอื่นเป็นการตอบแทนครับ ขอบคุณพี่มากๆ สำหรับการพิจารณาครับ 🙏
```

## หลัง

```text
พี่เมย์ครับ ขอรบกวนหน่อย เสาร์ที่ 7 นี้ผมต้องกลับต่างจังหวัดไปงานบวชน้องชาย พี่พอจะเข้ากะแทนผมช่วง 13.00–21.00 น. ได้ไหมครับ เดี๋ยวผมเข้ากะแทนพี่วันอื่นคืนให้ ขอบคุณมากครับ 🙏
```

## สิ่งที่เปลี่ยน

| ต้นฉบับ | หลังแก้ | รหัส | เหตุผล |
|---|---|---|---|
| สวัสดีครับพี่เมย์ ผมหวังว่าพี่จะสบายดีนะครับ | พี่เมย์ครับ | TH16, TH07 | คนที่เจอกันทุกวันไม่เปิด LINE แบบจดหมาย "หวังว่าจะสบายดี" แปลจาก "I hope you're well" |
| ผมต้องการที่จะขอความช่วยเหลือจากพี่ในเรื่องหนึ่ง | ขอรบกวนหน่อย | TH02, TH16 | สำนวนแชตที่คนไทยใช้ขอความช่วยเหลือจริง |
| เนื่องจาก... มีความจำเป็นต้องเดินทาง... เพื่อไปร่วมงาน | ต้องกลับ... ไปงาน | TH02, TH16 | ภาษาเขียนในแชต |
| ดังนั้น ผมจึง / ทั้งนี้ | (ตัด) | TH06 | คำเชื่อมในข้อความสั้นแค่ไม่กี่ประโยค |
| จะสามารถช่วย... ได้หรือไม่ | พอจะ... ได้ไหม | TH21, TH16 | "พอจะ...ได้ไหม" สุภาพแบบแชต |
| ยินดีที่จะเข้ากะแทนพี่ในวันอื่นเป็นการตอบแทน | เดี๋ยวผมเข้ากะแทนพี่วันอื่นคืนให้ | TH23, TH16 | "เป็นการตอบแทน" เป็นกรอบประโยคว่าง |
| ขอบคุณพี่มากๆ สำหรับการพิจารณา | ขอบคุณมาก | TH07 | แปลจาก "thank you for your consideration" |
| ครับ 6 ครั้ง | 3 ครั้ง | TH15 | คงไว้ที่ต้นข้อความ ตอนขอ และตอนขอบคุณ |

## ตรวจ guardrails

- ชื่อพี่เมย์ วันเสาร์ที่ 7 เวลา 13.00–21.00 น. งานบวชน้องชาย ครบทุกตัว
- ใช้ "ครับ" และ "ผม" ตามต้นฉบับ
- ขีด "–" ในช่วงเวลาไม่ใช่ปัญหา (TH28 กรณียกเว้น)
- ความยาว: 383 → 174 ตัวอักษร (สั้นลง 55%)
