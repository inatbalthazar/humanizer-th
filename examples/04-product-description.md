# ตัวอย่าง 04: คำอธิบายสินค้าร้านออนไลน์

- **บริบท:** เจ้าของแบรนด์สบู่ทำมือให้ AI เขียนคำอธิบายสินค้าสำหรับลงร้านออนไลน์ ได้ข้อความที่ยาวและเต็มไปด้วยคำโฆษณา
- **ระดับภาษา:** `casual`
- **โหมด:** `rewrite`

## ก่อน

```text
✨ สบู่ใบเตยออร์แกนิก บ้านสวนนภา – ยกระดับการดูแลผิวของคุณไปอีกขั้น ✨

ในยุคที่ผู้คนหันมาใส่ใจสุขภาพมากขึ้น การเลือกผลิตภัณฑ์ที่อ่อนโยนต่อผิวถือเป็นสิ่งที่สำคัญเป็นอย่างยิ่ง สบู่ใบเตยของเราถูกผลิตขึ้นด้วยความใส่ใจในทุกขั้นตอน โดยใช้น้ำมันมะพร้าวสกัดเย็นและใบเตยสดจากสวนในจังหวัดจันทบุรี ซึ่งอุดมไปด้วยคุณค่าจากธรรมชาติ ซึ่งช่วยให้ผิวของคุณรู้สึกสะอาด สดชื่น และชุ่มชื้นอย่างแท้จริง

🌿 คุณสมบัติเด่น:
• อ่อนโยน ปลอดภัย และเป็นมิตรกับผิว
• ปราศจากพาราเบนและสารกันเสีย
• กลิ่นหอมใบเตยธรรมชาติที่จะพาคุณไปสัมผัสความผ่อนคลายราวกับอยู่ท่ามกลางธรรมชาติ

ขนาด 100 กรัม ราคาเพียง 89 บาท

ไม่ใช่แค่สบู่ แต่คือการดูแลตัวเองที่คุณสมควรได้รับ 💚 สั่งซื้อเลยวันนี้!
```

## หลัง

```text
สบู่ใบเตยออร์แกนิก บ้านสวนนภา

ทำจากน้ำมันมะพร้าวสกัดเย็นกับใบเตยสดจากสวนที่จันทบุรี ผลิตอย่างใส่ใจทุกขั้นตอน ไม่มีพาราเบนและสารกันเสีย อ่อนโยน ปลอดภัยกับผิว ใช้แล้วผิวสะอาด สดชื่น ชุ่มชื้น กลิ่นใบเตยธรรมชาติ หอมแล้วผ่อนคลาย

ขนาด 100 กรัม ราคา 89 บาท สั่งได้เลย
```

## ตรวจ guardrails

- ชื่อสินค้า บ้านสวนนภา ออร์แกนิก น้ำมันมะพร้าวสกัดเย็น ใบเตยสด จันทบุรี ไม่มีพาราเบนและสารกันเสีย 100 กรัม 89 บาท ครบทุกตัว
- คำอ้างสรรพคุณ (อ่อนโยน ปลอดภัย สะอาด สดชื่น ชุ่มชื้น) คงไว้ทุกข้อ ไม่เพิ่มข้อใหม่
- ต้นฉบับไม่มีคำลงท้ายเพศ หลังแก้ก็ไม่ใส่
- ความยาว: 649 → 262 ตัวอักษร (สั้นลง 60%)
