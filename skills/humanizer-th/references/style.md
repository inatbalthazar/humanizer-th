# เลียนสไตล์ผู้เขียน

ใช้เมื่อผู้ใช้ส่งตัวอย่างงานเขียนมา แล้วอยากให้งานใหม่อ่านเหมือนคนเดียวกันเขียน ไฟล์นี้ใช้ร่วมกันทั้งสาม skill

| skill | ตัวอย่างที่มักได้ | ใช้ทำอะไร |
|---|---|---|
| `humanizer-th` | โพสต์ อีเมล แชตเก่าของผู้ใช้ | เขียนร่างใหม่หรือเขียนจากโจทย์ให้เป็นสำนวนของผู้ใช้ (โหมด `เลียนสไตล์`) |
| `localize-th` | ซับตอนก่อน ข้อความในแอปเวอร์ชันเดิม งานแปลเก่าของทีม | แปลส่วนใหม่ให้เข้ากับงานเดิม |
| `script-th` | บทเก่าของผู้ใช้ หรือตอนก่อนของเรื่องเดียวกัน | เขียนหรือเกลาตอนใหม่ให้เป็นสไตล์เดิม |

## ตัวอย่างที่ใช้ได้

ดู 4 เรื่องนี้ก่อนเริ่ม ถ้าข้อไหนไม่ผ่าน ให้บอกผู้ใช้ในหมายเหตุ

1. **เป็นงานของใคร:** งานของผู้ใช้เอง หรืองานที่ผู้ใช้มีสิทธิ์ใช้ เช่น โพสต์ของเพจที่ตัวเองเป็นแอดมิน ซับที่ทีมตัวเองแปล ถ้าเป็นงานของคนอื่น ดูหัวข้อ "เมื่อตัวอย่างเป็นงานของคนอื่น"
2. **ประเภทเดียวกับงานที่จะเขียน:** แชตใช้เลียนแชต โพสต์ใช้เลียนโพสต์ คนคนเดียวเขียน LINE หาเพื่อนกับอีเมลหาลูกค้าไม่เหมือนกัน ถ้าตัวอย่างปนหลายประเภท ให้ใช้เฉพาะชิ้นที่ตรงกับงาน หรือแยกโปรไฟล์ตามประเภท ห้ามเอามาเฉลี่ยรวมกัน
3. **มีพอไหม:** 3 ชิ้นขึ้นไป ยิ่งข้อความสั้นยิ่งต้องใช้หลายชิ้น เช่น แชตควรมี 10 ข้อความขึ้นไป ถ้ามีน้อยกว่านี้ยังทำได้ แต่บอกผู้ใช้ว่าโปรไฟล์ยังหยาบ เพราะลักษณะที่เห็นแค่ครั้งเดียวอาจเป็นเรื่องบังเอิญ
4. **คนเขียนเองหรือเปล่า:** ถ้าตัวอย่างมีรูปแบบจาก `patterns.md` หลายหมวดในเกือบทุกชิ้น เช่น เปิดลอยๆ (TH01) คำเชื่อมทุกประโยค (TH06) ปิดสรุปซ้ำ (TH12) ตัวอย่างนั้นอาจเป็นข้อความที่ AI เขียน ถ้าเลียนตาม ร่องรอย AI จะติดมาด้วย ให้บอกผู้ใช้ก่อน แล้วเสนอให้ส่งชิ้นอื่น หรือเกลาตัวอย่างก่อน

## ทำโปรไฟล์สำนวน

อ่านตัวอย่างให้ครบทุกชิ้นก่อน แล้วจดลักษณะที่**เห็นซ้ำในหลายชิ้น**ลงตาราง ทุกข้อต้องมีหลักฐานจากตัวอย่าง ยกคำสั้นๆ มาประกอบ ข้อไหนไม่เห็นในตัวอย่าง ให้เขียนว่า "ไม่เห็นในตัวอย่าง" แล้วใช้ค่าเริ่มต้นของ skill ห้ามเดาเติม

| หัวข้อ | ดูอะไร | ตัวอย่างที่จด |
|---|---|---|
| ระดับภาษา | ระดับไหนตาม `registers.md` | ไม่เป็นทางการ |
| เรียกตัวเอง เรียกคนอ่าน | สรรพนาม หรือไม่เรียกเลย | "ผม" ไม่เรียกคนอ่านตรงๆ ใช้ "ใครชอบ..." แทน |
| คำลงท้าย | คำไหน ถี่แค่ไหน อยู่ตรงไหน | "ครับ" ครั้งเดียวท้ายโพสต์ |
| ความยาวและการแบ่ง | ประโยคสั้นหรือยาว ย่อหน้ากี่บรรทัด ขึ้นบรรทัดใหม่บ่อยไหม | บรรทัดละวรรค เว้นบรรทัดทุก 2–3 บรรทัด |
| เปิดและปิด | ขึ้นต้นด้วยอะไร ลงท้ายด้วยอะไร | เปิดด้วยเรื่องที่เจอวันนั้น ปิดด้วยเวลาเปิดร้าน |
| คำติดปาก | คำหรือวลีที่เจอเกือบทุกชิ้น | "บอกตรงๆ" ตอนบอกความเห็นตัวเอง |
| ภาษาอังกฤษปน | คำไหนเขียนเป็นอักษรอังกฤษ คำไหนทับศัพท์ | ชื่อเมนูเขียนเป็นอังกฤษ |
| เครื่องหมายและสัญลักษณ์ | ไม้ยมก "..." "?" "!" อีโมจิ 555 วงเล็บ แฮชแท็ก | ไม่มีอีโมจิ ไม่มี "!" |
| ตัวเลขและวันที่ | เลขไทยหรือเลขอารบิก เขียนเวลาและราคาแบบไหน | "8 โมงถึงบ่าย 3" ราคาไม่มีคำว่า "บาท" |
| น้ำเสียง | ขำ ตรง อ่อนน้อม ประชดตัวเอง ชอบเล่าเรื่อง | เล่าเรื่องตัวเองขำๆ ไม่ขายของตรงๆ |
| สิ่งที่ไม่ทำ | ลักษณะที่ไม่เจอในตัวอย่างเลย | ไม่มีหัวข้อ ไม่มีคำโฆษณา |

ข้อสุดท้ายสำคัญเท่ากับข้ออื่น คนอ่านจำคนเขียนได้จากสิ่งที่เขาไม่ทำพอๆ กับสิ่งที่ทำ

**งานแปลและงานบท** ดูเพิ่มอีก 5 เรื่อง

| หัวข้อ | ใช้กับ | ดูอะไร |
|---|---|---|
| สรรพนามของตัวละคร | ซับ เกม บท | ใครเรียกใครว่าอะไร ลงตารางตัวละครตาม `characters.md` |
| คำศัพท์ | ซับ เกม UI | ชื่อเฉพาะ ชื่อไอเทม คำ UI ที่ใช้ไปแล้ว ลงอภิธานศัพท์ |
| การพูดกับผู้ใช้ | UI | ใช้ "คุณ" ไหม ใช้ "กรุณา" ไหม ปุ่มเป็นคำกริยาคำเดียวหรือเป็นวลี |
| ความแรงของภาษา | ซับ เกม บท | คำหยาบ คำสบถ มุก แปลหรือเขียนแรงแค่ไหน |
| จังหวะ | ซับ บท | ซับตัดบรรทัดตรงไหน ใช้ขีดนำบทสนทนาไหม บทแต่ละฉากยาวแค่ไหน เปิดและปิดตอนแบบไหน |

## เขียนตามโปรไฟล์

1. **เนื้อหามาจากร่างหรือโจทย์เท่านั้น:** ตัวอย่างใช้ดูวิธีเขียน ไม่ใช่แหล่งข้อมูล ห้ามยกเรื่อง ข้อมูล หรือประโยคจากตัวอย่างมาใส่ เช่น ตัวอย่างเล่าเรื่องแมวที่ร้าน งานใหม่ก็ต้องไม่มีแมว ยกเว้นคำทักทาย คำลงชื่อ หรือคำติดปากสั้นๆ ที่ผู้เขียนใช้ประจำ
2. **ถ้าสไตล์ต้องใช้ข้อมูลที่ไม่มี ห้ามแต่งเอง:** เช่น ผู้เขียนชอบเปิดด้วยเรื่องเล่า แต่ร่างไม่มีเรื่องเล่า ให้เปิดด้วยเรื่องที่มีในร่าง แล้วบอกในหมายเหตุว่าถ้าเล่าให้ฟังว่าเกิดอะไรขึ้น จะเขียนเปิดแบบนั้นให้ได้
3. **ถี่เท่าตัวอย่าง ไม่ถี่กว่า:** คำติดปากที่เจอชิ้นละครั้ง ใส่ครั้งเดียวก็พอ หรือไม่ใส่เลยถ้าไม่มีจุดที่เข้า ถ้าใส่ทุกย่อหน้าจะกลายเป็นล้อเลียน
4. **เริ่มจากสิ่งที่คนอ่านเห็นก่อน:** สรรพนาม คำลงท้าย การแบ่งบรรทัด วิธีเปิดและปิด ทำให้ตรงก่อน แล้วค่อยดูคำติดปากและน้ำเสียง

## สไตล์กับรูปแบบใน `patterns.md`

ตัวอย่างของผู้เขียนอาจมีลักษณะที่ `patterns.md` นับเป็นรูปแบบ AI ตัดสินแบบนี้

- **เรื่องรสนิยม** ได้แก่ อีโมจิและ "!" (TH29) คำลงท้ายถี่ (TH15) คำอังกฤษปน (TH19) รูปแบบหัวข้อและรายการ (TH17) จุลภาค (TH18) จุดท้ายประโยค (TH27) เปิดด้วยคำถาม (TH13) ถ้าเห็นซ้ำในหลายชิ้น ถือเป็นสไตล์ของผู้เขียน ใช้ได้ไม่เกินความถี่ในตัวอย่าง ถ้าไม่เห็นในตัวอย่าง ห้ามเติม
- **สำนวนแปลที่ทำให้อ่านยาก** ได้แก่ TH03 ได้ทำการ, TH04 "ถูก" แบบแปล, TH05 ซึ่งต่อกันยาว, TH07 สำนวนแปล ไม่เลียน แม้ผู้เขียนจะใช้ประจำ เพราะคนอ่านอ่านยากขึ้นจริง ให้บอกในหมายเหตุว่าข้อนี้ไม่ได้เลียน ถ้าผู้ใช้ยืนยันว่าต้องการ ค่อยใส่
- **คำพูดของผู้ช่วย AI (TH26):** ไม่ใช้เลย
- **รูปแบบอื่น:** เลียนได้ถ้าเห็นซ้ำในหลายชิ้นและอ่านแล้วไม่สะดุด ถ้าไม่แน่ใจ ให้ไม่ใช้ แล้วบอกในหมายเหตุ

## สิ่งที่ไม่เลียน

- **คำผิด:** สะกดผิดโดยไม่ได้ตั้งใจ เช่น "นะค่ะ" (ที่ถูกคือ "นะคะ") "อนุญาติ" (ที่ถูกคือ "อนุญาต") ไม่เลียน ใช้ตัวสะกดที่ถูก ส่วนการเขียนแบบภาษาพูดที่ตั้งใจ เช่น "มากกก" "เค้า" "ป่ะ" "555" ใช้ได้ตามตัวอย่าง เฉพาะงานระดับกันเองและไม่เป็นทางการ
- **ข้อมูลส่วนตัว:** ชื่อคน เบอร์โทร ที่อยู่ ที่อยู่ในตัวอย่าง ห้ามนำไปใช้ในงานใหม่
- **ประโยคเฉพาะตัว:** ห้ามยกประโยคจากตัวอย่างมาทั้งประโยค

## เมื่อตัวอย่างเป็นงานของคนอื่น

- **เขียนแทนโดยเจ้าตัวรู้:** เช่น แอดมินเขียนโพสต์ในนามเจ้าของร้าน เลขาร่างข้อความให้ผู้บริหาร ทีมแปลซีซันใหม่ต่อจากทีมเดิม ทำได้ตามปกติ
- **นักเขียนหรือคนดัง:** เลียนแนวกว้างๆ ได้ เช่น จังหวะสั้น น้ำเสียงประชด เพื่อฝึกเขียนหรือหาแนว แต่ห้ามลอกประโยคหรือวลีเฉพาะตัว ห้ามเขียนในนามคนนั้น และห้ามทำให้คนอ่านเข้าใจว่าคนนั้นเขียน
- **ปลอมเป็นคนอื่น:** ถ้าจุดประสงค์คือให้คนอ่านเชื่อว่าอีกคนเป็นคนเขียน ทั้งที่คนนั้นไม่รู้หรือไม่ได้อนุญาต เช่น แชตในชื่อหัวหน้า ข้อความในชื่อคนในครอบครัว โพสต์ในชื่อคนดัง ให้ปฏิเสธ แล้วบอกเหตุผลสั้นๆ
- **หลบเครื่องมือตรวจจับ AI:** ถ้าผู้ใช้บอกว่าจะใช้สไตล์ของตัวเองเพื่อให้ detector จับไม่ได้ หรือเพื่อส่งงานที่ห้ามใช้ AI ให้บอกตรงๆ ว่า skill นี้ไม่ได้ทำเพื่อเรื่องนั้น

## เก็บโปรไฟล์ไว้ใช้ครั้งหน้า

ถ้าผู้ใช้ขอโปรไฟล์ หรือบอกว่าจะใช้สไตล์นี้อีก ให้ส่งโปรไฟล์ตามแบบด้านล่าง ผู้ใช้เก็บไว้แล้ววางแทนตัวอย่างในครั้งหน้าได้ ถ้าเครื่องมือที่ใช้อยู่เขียนไฟล์ได้และผู้ใช้ขอให้บันทึก ให้บันทึกเป็นไฟล์ในโฟลเดอร์งาน เช่น `style-profile.md`

```text
โปรไฟล์สำนวน: [ชื่อที่ผู้ใช้ตั้ง เช่น โพสต์เพจร้าน]
ใช้กับ: [ประเภทงาน]
ทำจาก: [จำนวนชิ้นของตัวอย่าง]

- ระดับภาษา:
- เรียกตัวเอง / เรียกคนอ่าน:
- คำลงท้าย:
- ความยาวและการแบ่ง:
- เปิดและปิด:
- คำติดปาก:
- ภาษาอังกฤษปน:
- เครื่องหมายและสัญลักษณ์:
- ตัวเลขและวันที่:
- น้ำเสียง:
- ไม่ทำ:
- ไม่ได้เลียน: [ลักษณะที่ตั้งใจไม่ตาม และเหตุผล]
```

ถ้าผู้ใช้ส่งโปรไฟล์ที่เคยทำไว้มา ให้ใช้ตามนั้นได้เลย ไม่ต้องขอตัวอย่างใหม่ ถ้าส่งทั้งโปรไฟล์และตัวอย่างใหม่ ให้ปรับโปรไฟล์ตามตัวอย่างใหม่ แล้วบอกว่าเปลี่ยนข้อไหน
