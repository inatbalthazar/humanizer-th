# ตารางคำและสำนวนแข็ง → ทางเลือกที่เป็นธรรมชาติ

ใช้ตอนแก้ (`rewrite`, `edit`) เพื่อหาคำแทนอย่างรวดเร็ว ทุกแถวเชื่อมกับรหัสรูปแบบใน `patterns.md`

## วิธีใช้

- **ตารางนี้เป็นตัวช่วย ไม่ใช่ find-and-replace** ต้องอ่านทั้งประโยคก่อน บางครั้งต้องเรียงประโยคใหม่ ไม่ใช่แค่เปลี่ยนคำ
- ดูคอลัมน์ "ระดับภาษา" ทุกครั้ง ทางเลือกบางตัวใช้ได้เฉพาะ `chat`/`casual`
- "(ตัด)" แปลว่าลบทิ้งได้เมื่อประโยคยังมีความหมายครบ ถ้าตัดแล้วข้อมูลหายให้เก็บไว้
- ถ้าคำนั้นอยู่ในเครื่องหมายคำพูดของคนอื่น ลิงก์ โค้ด หรือชื่อเฉพาะ ห้ามแตะ
- ตัวย่อระดับภาษา: **ทุกระดับ** = `chat` `casual` `professional` `formal`

## TH01 ประโยคเปิดลอยๆ

| คำ/สำนวนแข็ง | ทางเลือก | ระดับภาษา | หมายเหตุ |
|---|---|---|---|
| ในยุคดิจิทัลปัจจุบัน | (ตัด) เข้าเรื่องเลย | ทุกระดับ | เก็บไว้ถ้ายุคสมัยเป็นเนื้อหาจริง |
| ในโลกที่เปลี่ยนแปลงอย่างรวดเร็ว | (ตัด) | ทุกระดับ | ถ้าต้องการเกริ่น ใช้ข้อเท็จจริงแทน |
| ปฏิเสธไม่ได้เลยว่า | (ตัด) | ทุกระดับ | ตัดแล้วประโยคที่เหลือยังพูดได้ตรงๆ |

## TH02 ทำนามด้วย การ/ความ เกินจำเป็น

| คำ/สำนวนแข็ง | ทางเลือก | ระดับภาษา | หมายเหตุ |
|---|---|---|---|
| ทำการตรวจสอบ | ตรวจ / เช็ก | `chat` `casual` ใช้ "เช็ก" | |
| ทำการแก้ไข | แก้ | ทุกระดับ | |
| ดำเนินการส่ง | ส่ง | ทุกระดับ | "ดำเนินการ" ในหนังสือราชการอาจคงไว้ |
| มีความเข้าใจ | เข้าใจ | ทุกระดับ | |
| เกิดการเปลี่ยนแปลง | เปลี่ยน | ทุกระดับ | |
| ให้ความช่วยเหลือ | ช่วย | ทุกระดับ | "ให้ความสำคัญ" เป็นสำนวนตายตัว ไม่ต้องแก้ |

## TH03 ได้ทำการ / มีการ / ได้มีการ

| คำ/สำนวนแข็ง | ทางเลือก | ระดับภาษา | หมายเหตุ |
|---|---|---|---|
| ได้ทำการ + กริยา | (ตัด "ได้ทำการ") ใช้กริยาตรง | ทุกระดับ | อาจเติม "แล้ว" ท้ายประโยคถ้าต้องบอกว่าเสร็จ |
| ได้มีการปรับปรุง | ปรับปรุง | ทุกระดับ | |
| มีการประชุม (ผู้ทำชัด) | ประชุม | ทุกระดับ | ถ้าไม่ระบุผู้ทำ "มีการประชุม" ใช้ได้ |

## TH06 คำเชื่อมทุกประโยค

|---|---|---|---|

| ทั้งนี้ | (ตัด) | ทุกระดับ | หนังสือราชการใช้เป็นสำนวนมาตรฐาน |

## TH07 สำนวนแปลตรงจากอังกฤษ
