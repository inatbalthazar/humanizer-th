# ระดับภาษา คำลงท้าย และสรรพนาม

ใช้ไฟล์นี้ตอนขั้นแรกของขั้นตอน (ระบุระดับภาษา) และตอนตรวจ TH14, TH15, TH16 ในแคตตาล็อก `patterns.md`

## 1. เลือกระดับภาษาอย่างไร

ชื่อระดับใช้ตามที่เรียนในวิชาภาษาไทย ซึ่งแบ่งระดับภาษาเป็น 5 ระดับ คือ พิธีการ ทางการ กึ่งทางการ ไม่เป็นทางการ และกันเอง skill นี้ใช้ 4 ระดับหลัง ส่วนระดับพิธีการ (สุนทรพจน์ คำกล่าวในพิธี) อยู่นอกขอบเขต

| ระดับ | ในตำรา | ช่องทางที่ skill นี้จัดให้ |
|---|---|---|
| `กันเอง` | ภาษาปาก ใช้กับคนสนิทมาก | แชตกับเพื่อน คนในครอบครัว คนสนิท |
| `ไม่เป็นทางการ` | ระดับสนทนา ใช้กับคนที่ไม่สนิทมากหรือต้องระวังมารยาท | โพสต์โซเชียล บล็อก แชตกับหัวหน้าหรือเพื่อนร่วมงาน |
| `กึ่งทางการ` | ประชุมกลุ่มย่อย การบรรยาย | อีเมลงานประจำวัน ข้อความถึงลูกค้า |
| `ทางการ` | รายงาน ประกาศ จดหมายราชการหรือธุรกิจ | รายงาน หนังสือราชการ เอกสารวิชาการ จดหมายธุรกิจที่เป็นเรื่องเป็นราว |

ถ้าผู้ใช้ไม่ระบุ ให้เดาจากเนื้อหาและช่องทาง แล้วบอกในสรุปว่าเลือกระดับไหน

| สัญญาณในข้อความ | ระดับที่น่าจะใช่ |
|---|---|
| ประโยคสั้น มีคำอย่าง "นะ" "เลย" "อะ" "555" ผู้รับเป็นเพื่อนหรือคนสนิท | `กันเอง` |
| โพสต์เพจ แคปชัน บล็อกส่วนตัว หรือแชตกับหัวหน้าและเพื่อนร่วมงาน | `ไม่เป็นทางการ` |
| อีเมลงาน ข้อความถึงลูกค้า มี "เรียน" "ขอบคุณครับ/ค่ะ" ต้องการความชัดเจนและสุภาพ | `กึ่งทางการ` |
| รายงาน หนังสือราชการ เอกสารวิชาการ ไม่มีผู้รับเฉพาะคน | `ทางการ` |

ถ้าสัญญาณขัดกัน (เช่น อีเมลงานที่เขียนสบายๆ มาก) ให้ยึดผู้รับเป็นหลัก ไม่ใช่ตัวข้อความ ถ้ายังเดาไม่ได้จริงๆ ให้ถามคำถามเดียว เช่น "ข้อความนี้ส่งถึงใคร" แล้วเลือกจากคำตอบ

**ห้ามยกระดับภาษาให้สูงกว่าต้นฉบับโดยไม่จำเป็น** ถ้าผู้เขียนเขียน `ไม่เป็นทางการ` อยู่แล้ว ให้คงไว้แล้วตัดเฉพาะร่องรอย AI

## 2. ประโยคเดียวกัน 4 ระดับ

เนื้อหา: ประชุมเลื่อนเป็นพรุ่งนี้บ่ายสองโมง เพราะวิทยากรไม่ว่าง (ตัวอย่างนี้สมมติผู้เขียนเป็นผู้ชาย ถ้าเป็นผู้หญิงเปลี่ยน "ครับ" เป็น "ค่ะ")

| ระดับ | ข้อความ |
|---|---|
| `กันเอง` | ประชุมเลื่อนเป็นพรุ่งนี้บ่ายสองนะ วิทยากรไม่ว่าง |
| `ไม่เป็นทางการ` | ประชุมเลื่อนไปพรุ่งนี้ตอนบ่ายสองนะครับ พอดีวิทยากรไม่ว่าง |
| `กึ่งทางการ` | ขอแจ้งว่าการประชุมเลื่อนเป็นพรุ่งนี้ เวลา 14.00 น. เนื่องจากวิทยากรไม่สะดวกเข้าร่วมครับ |
| `ทางการ` | ขอแจ้งเลื่อนการประชุมเป็นวันพรุ่งนี้ เวลา 14.00 น. เนื่องจากวิทยากรไม่สามารถเข้าร่วมได้ |

ทั้ง 4 ระดับสั้นกว่าประโยคแบบ AI ที่เป็นต้นฉบับ เช่น "ขอแจ้งให้ทราบว่าการประชุมได้ถูกเลื่อนออกไปเป็นวันพรุ่งนี้ เวลา 14.00 น. เนื่องจากวิทยากรไม่สามารถเข้าร่วมได้ จึงเรียนมาเพื่อโปรดทราบ" (TH03, TH04, TH16)

## 3. รายละเอียดแต่ละระดับ

### `กันเอง`: แชตกับเพื่อน คนในครอบครัว คนสนิท

- ประโยคสั้น ละประธานได้ทุกครั้งที่บริบทชัด
- ใช้คำเล็กๆ เชื่อมความ เช่น "แล้วก็" "เลย" "พอดี" แทนคำเชื่อมยาว
- คำลงท้ายตามความสัมพันธ์ ไม่ต้องใส่ทุกข้อความ
- ยอมรับได้: คำอังกฤษที่คนใช้จริง ("confirm" "ok") และ "555" ไม่ใส่อีโมจิหรือ "!" (TH29)
- ระวัง: TH16 (ภาษาราชการใน LINE), TH17 (หัวข้อ ตัวหนา บูลเล็ต), TH14, TH15

### `ไม่เป็นทางการ`: โพสต์โซเชียล บล็อก แชตกับหัวหน้าหรือเพื่อนร่วมงาน

- อ่านสบาย เหมือนเล่าให้คนอ่านฟัง แต่ยังรักษามารยาท
- แชตกับหัวหน้าหรือรุ่นพี่ใช้ภาษาพูดได้ แต่ใส่คำลงท้ายสุภาพตามที่ผู้เขียนใช้
- ใช้ "เรา" หรือ "ผม/ฉัน" ได้ตามที่ผู้เขียนใช้ ไม่ต้องเรียกผู้อ่านว่า "คุณ" ทุกประโยค
- ย่อหน้าสั้น เว้นบรรทัดให้อ่านง่าย ไม่ใส่อีโมจิหรือ "!" (TH29)
- ระวัง: TH01, TH09, TH13, TH17, TH24, TH25, TH12

### `กึ่งทางการ`: อีเมลงานประจำวัน ข้อความถึงลูกค้า

- สุภาพและกระชับ ไม่แข็งแบบหนังสือราชการ
- เปิดด้วยเรื่องที่ต้องการบอกภายในประโยคแรก ปิดด้วยสิ่งที่ต้องการให้ผู้รับทำ ถ้ามี
- คำลงท้ายสุภาพใช้เป็นจังหวะ (ต้นอีเมลหรือท้ายอีเมล และจุดที่ต้องการความนอบน้อม) ไม่ใส่ทุกประโยค
- ระวัง: TH02, TH03, TH06, TH12, TH16, TH21

### `ทางการ`: รายงาน หนังสือราชการ เอกสารวิชาการ

- ใช้ภาษาเขียน ไม่ใช้ภาษาพูด ("เพราะ" → "เนื่องจาก" ได้ "เลย" → "จึง")
- ไม่ต้องมีคำลงท้ายสุภาพ ยกเว้นรูปแบบจดหมายที่กำหนดไว้ (เช่น "ขอแสดงความนับถือ")
- คงคำที่เป็นศัพท์หรือธรรมเนียมของเอกสารประเภทนั้นไว้ เช่น "ดำเนินการ" "เรียน" "โปรดพิจารณา"
- "ดังนั้น" "อย่างไรก็ตาม" "ทั้งนี้" ใช้ได้ แต่ไม่ควรเกิน 1–2 ครั้งต่อย่อหน้า
- ยังต้องกระชับ "ไม่อืดยืดยาว" คือตัด TH02, TH03, TH10 ที่เป็นแค่ความยาวเปล่า
- ระวัง: TH02, TH03, TH05, TH07, TH10, TH22, TH23

## 4. คำลงท้ายและสรรพนาม

### กฎ

1. **ห้ามสลับเพศผู้เขียน** ถ้าต้นฉบับใช้ "ครับ" ให้ใช้ "ครับ" ตลอด ถ้าใช้ "ค่ะ/คะ" ให้ใช้ "ค่ะ/คะ" ตลอด
2. **ถ้าต้นฉบับมีคำลงท้ายสองเพศปนกัน** ให้ตรวจก่อนว่ามีหลายคนเขียน (เช่น แชตของทีม) หรือเป็นความผิดพลาด (TH15) ถ้าไม่แน่ใจ ให้คงไว้และถามผู้ใช้
3. **ไม่ใส่คำลงท้ายทุกประโยค** ใส่ที่ต้นหรือท้ายข้อความ และจุดที่ต้องการความนอบน้อมหรือความเป็นมิตรจริงๆ
4. **ถ้าต้นฉบับไม่มีคำลงท้ายและระดับภาษาต้องใช้** (เช่น `กึ่งทางการ`)
   - ค่าเริ่มต้น: ไม่ต้องหยุดถามก่อน ให้ส่งผลลัพธ์ที่ใช้โครงประโยคไม่ต้องมีคำลงท้ายเพศ (เช่น "ขอบคุณสำหรับ..." "รบกวน...") แล้วถามในหมายเหตุว่าต้องการให้เติม ครับ/ค่ะ ไหม
   - ข้อความในนามบริษัท ฝ่าย หรือเพจ มักไม่ต้องมีคำลงท้ายเพศอยู่แล้ว
   - ถามก่อนเขียน เฉพาะเมื่อขาดคำลงท้ายแล้วจะฟังห้วนจนเสียมารยาทจริงๆ เช่น ข้อความส่วนตัวถึงผู้ใหญ่ใน `กันเอง` และถามเป็นคำถามเดียวว่าเขียนในนามผู้ชายหรือผู้หญิง
   - ห้ามเดาเพศจากชื่อ
5. **ห้ามเพิ่มระดับความสุภาพเกินต้นฉบับ** เช่น เติม "นะคะ/นะครับ" ทุกบรรทัดในข้อความที่ผู้เขียนไม่ได้ใช้ (TH15)

### คำลงท้ายที่ไม่ระบุเพศ

ใช้ได้ใน `กันเอง` และ `ไม่เป็นทางการ` เมื่อต้นฉบับไม่มีคำลงท้ายเพศ

| คำ | ความรู้สึก | ตัวอย่าง |
|---|---|---|
| นะ | อ่อนลง ขอร้องหรือยืนยันเบาๆ | ประชุมเลื่อนนะ |
| เลย | เน้น | ดีมากเลย |
| ละ / แล้ว | บอกว่าเสร็จหรือเปลี่ยนสถานะ | ส่งแล้ว |
| เนอะ | ชวนให้เห็นด้วย | ร้อนจังเนอะ |
| อะ / นะ | ภาษาพูดมาก ใช้เฉพาะ `กันเอง` | ไม่ว่างอะ |

### สรรพนาม

| สถานการณ์ | ที่เลือกได้ | หมายเหตุ |
|---|---|---|
| ผู้เขียนพูดถึงตัวเอง | ผม / ฉัน / เรา / ชื่อเล่น | ใช้ตามที่ต้นฉบับใช้ ถ้าไม่มีให้ละประธาน |
| พูดกับผู้อ่านทั่วไป (`ไม่เป็นทางการ`) | ละประธาน / เพื่อนๆ / ทุกคน | หลีกเลี่ยง "คุณ" ซ้ำ (TH14) |
| พูดกับลูกค้า (`กึ่งทางการ`) | ลูกค้า / ท่าน / คุณ + ชื่อ | เลือกอย่างเดียวทั้งชิ้น ไม่สลับ |
| พูดถึงองค์กร | เรา / บริษัท / ร้าน / ชื่อแบรนด์ | อย่าสลับ "เรา" กับ "บริษัท" ในย่อหน้าเดียวโดยไม่มีเหตุผล |
| `ทางการ` | ละประธาน / ชื่อหน่วยงาน / ท่าน (ผู้รับ) | หนังสือราชการใช้ "เรียน" ตามธรรมเนียม |

### ข้อควรระวัง

- **กับผู้ใหญ่และคนที่ไม่สนิท** อย่าลดความสุภาพของต้นฉบับ ถ้าผู้เขียนใส่ "ครับ" "ค่ะ" บ่อย อาจเป็นเพราะผู้รับ ให้ตัดเฉพาะส่วนที่ซ้ำจนรกจริงๆ
- **ข้อความที่ผู้เขียนเป็นแอดมินเพจหรือแบรนด์** ให้ยึดคำลงท้ายที่เพจใช้ประจำ ถ้าไม่เคยมีให้ถามหรือเลือกแบบเป็นกลางและบอกผู้ใช้
- **คำพูดที่ยกมา** ไม่แตะคำลงท้ายหรือสรรพนามภายในเครื่องหมายคำพูดของคนอื่น (ข้อห้ามข้อ 2)

## 5. ตารางสรุป

| | `กันเอง` | `ไม่เป็นทางการ` | `กึ่งทางการ` | `ทางการ` |
|---|---|---|---|---|
| ความยาวประโยค | สั้นมาก | สั้นถึงกลาง | กลาง | กลางถึงยาว แต่ไม่อืด |
| ละประธาน | บ่อย | บ่อย | พอควร | ตามธรรมเนียม |
| คำลงท้าย | ตามความสนิท | เล็กน้อย | ต้นและท้าย | แทบไม่มี |
| ภาษาพูด | ได้ | ได้พอควร | เลี่ยง | ห้าม |
| คำเชื่อมยาว (ดังนั้น ทั้งนี้) | เลี่ยง | เลี่ยง | พอควร | ปกติ |
| อีโมจิ และ "!" | ไม่ใช้ | ไม่ใช้ | ไม่ใช้ | ไม่ใช้ |
