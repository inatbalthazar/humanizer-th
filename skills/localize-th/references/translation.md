# หลักการแปลและรูปแบบภาษาแปล

ไฟล์นี้ใช้ทุกครั้งที่แปลอังกฤษเป็นไทย ส่วนแรกคือหลักการ ส่วนที่สองคือรูปแบบภาษาแปล LT01–LT12 ที่ทำให้คนอ่านรู้ว่าเป็นงานแปล

รูปแบบภาษาแบบ AI ทั่วไป (TH01–TH29) อยู่ใน `patterns.md` ใช้คู่กัน ถ้าซ้ำกัน ให้อ้างรหัสที่ตรงกว่า เช่น "ถูก" แบบแปลจาก passive ใช้ TH04

## หลักการ

1. **อ่านทั้งฉากหรือทั้งหน้าจอก่อน** บรรทัดเดียวมักแปลได้หลายแบบ บริบทเป็นตัวตัดสิน
2. **แปลเจตนา ไม่ใช่แปลคำ** ถามตัวเองว่าคนไทยในสถานการณ์นี้จะพูดว่าอะไร แล้วเขียนแบบนั้น
3. **ความหมายต้องครบ** ย่อคำได้ เรียงประโยคใหม่ได้ แต่ข้อมูล อารมณ์ และเจตนาต้องอยู่ครบ
4. **รักษาน้ำเสียง** ตัวละครที่หยาบต้องยังหยาบ ข้อความ UI ที่เป็นกันเองต้องยังเป็นกันเอง ไม่ทำให้สุภาพขึ้นหรือห้วนลง
5. **อ่านทวนโดยไม่ดูต้นฉบับ** ถ้าสะดุดตรงไหน ตรงนั้นยังเป็นภาษาแปล

### ความแรงของคำหยาบ

แปลให้แรงเท่าต้นฉบับ ถ้าผู้ใช้กำหนดเรตไว้ ให้ใช้ตามเรต

| ระดับ | ตัวอย่างอังกฤษ | ตัวอย่างไทย |
|---|---|---|
| เบา | damn, oh crap, shoot | บ้าเอ๊ย / โธ่เว้ย / ให้ตายสิ / แย่แล้ว |
| กลาง | hell, bastard, shit | เวร / ชิบหาย / ไอ้บ้า / ไอ้สารเลว |
| แรง | คำหยาบที่สุดในภาษาอังกฤษ | ใช้คำหยาบไทยที่แรงเท่ากัน เฉพาะเรื่องที่เรตผู้ใหญ่ |

ไม่ต้องแปลคำหยาบทุกคำ ภาษาอังกฤษใช้คำหยาบเป็นคำเสริมบ่อยกว่าภาษาไทย ถ้าใส่ทุกคำจะฟังแรงเกินต้นฉบับ ให้เลือกใส่ตรงที่เน้นอารมณ์

## รูปแบบภาษาแปล

### LT01 สรรพนามครบทุกประโยค

**ทำไมดูเป็นงานแปล:** ประโยคอังกฤษต้องมีประธาน ภาษาไทยไม่ต้อง พอแปล I, you, he, she ทุกตัว บทพูดจะแข็งและซ้ำ

**ต้นฉบับ:**
> I don't know. I told you I was busy.

**แปลแข็ง:**
> ฉันไม่รู้ ฉันบอกคุณแล้วว่าฉันยุ่ง

**แปลดี:**
> ไม่รู้สิ บอกแล้วไงว่ายุ่ง

**ไม่ต้องแก้เมื่อ:**
- ต้องการเน้นว่าเป็นคนนี้ เช่น "ฉันนี่แหละที่ทำ"
- ตัดแล้วไม่รู้ว่าใครทำอะไรกับใคร โดยเฉพาะฉากที่มีหลายคน

### LT02 แปลตามพจนานุกรม ผิดบริบท

**ทำไมดูเป็นงานแปล:** คำอังกฤษหลายคำมีหลายความหมาย ถ้าเลือกความหมายแรกในพจนานุกรม จะได้ประโยคที่ถูกทุกคำแต่ผิดเรื่อง

| คำ | ความหมายที่มักเลือกผิด | ความหมายตามบริบท |
|---|---|---|
| save | ช่วยชีวิต | บันทึก (UI) / เก็บเงิน / ประหยัด |
| charge | ชาร์จ | คิดเงิน / ตั้งข้อหา / พุ่งเข้าใส่ |
| fire | ไฟ | ไล่ออก / ยิง |
| run | วิ่ง | เปิดใช้ (โปรแกรม) / บริหาร / ลงสมัคร |
| deal | ข้อตกลง | ตกลง / รับมือ (deal with) / ของถูก |
| play | เล่น | เปิด (เพลง วิดีโอ) / แสดง |
| miss | พลาด | คิดถึง |
| figure | ตัวเลข | คิดออก (figure out) / หุ่น |

**ต้นฉบับ:**
> We need to save before the boss fight.

**แปลแข็ง:**
> เราต้องช่วยชีวิตก่อนการต่อสู้กับบอส

**แปลดี:**
> เซฟเกมก่อนตีบอสนะ

**ไม่ต้องแก้เมื่อ:**
- ความหมายแรกตรงกับบริบทอยู่แล้ว

### LT03 "มัน" "สิ่งนี้" แทน it, this, that

**ทำไมดูเป็นงานแปล:** it, this, that ในภาษาอังกฤษมักไม่ต้องแปล หรือควรแปลเป็นสิ่งที่พูดถึงจริงๆ ดูเพิ่มที่ TH08

**ต้นฉบับ:**
> This is amazing. It's exactly what I wanted.

**แปลแข็ง:**
> สิ่งนี้มันยอดเยี่ยมมาก มันคือสิ่งที่ฉันต้องการเลย

**แปลดี:**
> สุดยอดเลย อยากได้แบบนี้แหละ

**ไม่ต้องแก้เมื่อ:**
- "มัน" หมายถึงสัตว์หรือสิ่งของที่พูดถึงอยู่ และคนไทยก็พูดแบบนั้น เช่น "แมวมันหิว"
- บทพูดแบบกันเองที่ใช้ "มัน" เป็นคำเสริม เช่น "มันก็ต้องลองดูแหละ"

### LT04 สำนวนอังกฤษแปลตรงตัว

**ทำไมดูเป็นงานแปล:** สำนวนแปลตรงตัวแล้วคนไทยไม่เข้าใจ หรือเข้าใจผิด

| ต้นฉบับ | แปลตรงตัว | ที่คนไทยพูด |
|---|---|---|
| break a leg | ขอให้ขาหัก | ขอให้โชคดี / สู้ๆ |
| piece of cake | ชิ้นเค้ก | ง่ายจะตาย / หมูๆ |
| I'm dying | ฉันกำลังจะตาย | ขำจะตายอยู่แล้ว / ไม่ไหวแล้ว (ตามบริบท) |
| it's not rocket science | ไม่ใช่วิทยาศาสตร์จรวด | ไม่ได้ยากขนาดนั้น |
| my bad | ความเลวของฉัน | โทษที / ผิดเอง |
| cut it out | ตัดมันออก | พอได้แล้ว / เลิกเถอะ |

**ไม่ต้องแก้เมื่อ:**
- เรื่องตั้งใจเล่นกับความหมายตรงตัวของสำนวน ให้แปลเพื่อรักษามุก แล้วบอกในบันทึก

### LT05 คำอุทานแปลตรง

**ทำไมดูเป็นงานแปล:** "โอ้พระเจ้า" "ว้าว" "เอาล่ะ" ในทุกฉาก เป็นภาษาซับแปลที่คนไทยจำได้ทันที

| ต้นฉบับ | แปลแข็ง | ทางเลือก |
|---|---|---|
| Oh my God | โอ้พระเจ้า | ตายแล้ว / พระเจ้าช่วย / อะไรเนี่ย |
| Wow | ว้าว | โห / เฮ้ย / สุดยอด |
| Well, ... | เอาล่ะ ... / ก็ ... | ละไว้ / คือว่า / ก็นะ |
| Oh no | โอ้ไม่ | แย่แล้ว / ไม่นะ / ซวยแล้ว |
| Come on | มาเถอะ | เร็วเข้า / เอาน่า / ไม่เอาน่า (ตามบริบท) |
| Hey | เฮ้ | นี่ / เฮ้ย / ชื่อคนที่เรียก |

**ไม่ต้องแก้เมื่อ:**
- ตัวละครเป็นคนเคร่งศาสนาและพูดถึงพระเจ้าจริงๆ
- "เฮ้" "ว้าว" เข้ากับตัวละครวัยรุ่นที่พูดแบบนั้นอยู่แล้ว ใช้ได้บ้าง แต่อย่าใช้ทุกครั้ง

### LT06 มารยาทแบบฝรั่ง

**ทำไมดูเป็นงานแปล:** ฝรั่งพูด thank you, sorry, how are you บ่อยกว่าคนไทย แปลครบทุกครั้งแล้วบทพูดจะฟังห่างเหิน

**ต้นฉบับ:**
> - Hey, how are you?
> - Good, thanks. You?

**แปลแข็ง:**
> - สวัสดี คุณสบายดีไหม
> - สบายดี ขอบคุณ แล้วคุณล่ะ

**แปลดี (เพื่อนเจอกัน):**
> - อ้าว เป็นไงบ้าง
> - ก็ดี แล้วแกล่ะ

**ไม่ต้องแก้เมื่อ:**
- เป็นการทักทายทางการ เช่น งานเลี้ยงธุรกิจ คนเพิ่งรู้จักกัน
- ข้อความ UI ที่ต้องขอบคุณผู้ใช้จริงๆ เช่น หลังชำระเงิน

### LT07 คำเรียกแสดงความรักและคำเรียกเพื่อน

**ทำไมดูเป็นงานแปล:** honey, sweetie, babe, dude, bro, man แปลเป็น "ที่รัก" "เพื่อน" ทุกครั้ง ฟังเหมือนซับหนังฝรั่งยุคเก่า

**ทางเลือก:**
- คู่รัก: ชื่อเล่น / ตัวเอง / เค้า / ละไว้ ใช้ "ที่รัก" เฉพาะตอนที่ตัวละครหวานจริงๆ
- แม่เรียกลูก (honey, sweetie): ลูก / ชื่อเล่น
- เพื่อนผู้ชาย (dude, bro, man): ละไว้ / ชื่อเล่น / เพื่อน (นานๆ ครั้ง) / มึง (ถ้าเรตและความสัมพันธ์ได้)
- คนแปลกหน้า (sir, ma'am): คุณ / พี่ / ลุง / ป้า / ละไว้ ดู `characters.md`

**ไม่ต้องแก้เมื่อ:**
- ตัวละครตั้งใจพูดแบบฝรั่ง เช่น ตัวละครที่เพิ่งกลับจากเมืองนอกในเรื่องไทย

### LT08 คำถามท้ายประโยค

**ทำไมดูเป็นงานแปล:** right? isn't it? don't you? แปลเป็น "ใช่ไหม" ทุกครั้ง

**ต้นฉบับ:**
> You're coming tomorrow, right?

**แปลแข็ง:**
> คุณจะมาพรุ่งนี้ ใช่ไหม

**แปลดี:**
> พรุ่งนี้มาใช่มั้ย / พรุ่งนี้มานะ

**ทางเลือก:** ใช่มั้ย / ไม่ใช่เหรอ / ใช่ป่ะ / นะ / เนอะ / ล่ะสิ เลือกตามระดับภาษาและอารมณ์

**ไม่ต้องแก้เมื่อ:**
- ตัวละครกำลังถามยืนยันจริงจัง เช่น ฉากสอบสวน

### LT09 เวลา วันที่ และหน่วยในบทพูด

**ทำไมดูเป็นงานแปล:** "บ่ายสามโมง" คนไทยพูด "15.00 น." คนไทยเขียน "3 p.m." ไม่มีใครพูด ในบทพูดให้ใช้แบบที่คนไทยพูด

| ต้นฉบับ | แปลแข็ง | ในบทพูด |
|---|---|---|
| 3 a.m. | 3 นาฬิกา | ตีสาม |
| 8 p.m. | 8 โมงเย็น | สองทุ่ม |
| 7:30 a.m. | 7:30 น. | เจ็ดโมงครึ่ง |
| twenty bucks | ยี่สิบเหรียญ | ยี่สิบดอลลาร์ (หรือคงตามที่ผู้ใช้กำหนด) |

**กฎ:**
- ห้ามเปลี่ยนค่าของตัวเลข แปลงได้แค่วิธีเขียนหรือวิธีพูด
- หน่วยวัด (ไมล์ ฟุต ปอนด์) คงตามต้นฉบับเป็นค่าเริ่มต้น แปลงเป็นหน่วยเมตริกเมื่อผู้ใช้ขอ หรือเมื่อตัวเลขไม่สำคัญต่อเรื่องและคนดูไม่เข้าใจหน่วยเดิม
- ในไฟล์ UI ห้ามแปลงรูปแบบวันที่หรือเวลาเอง ถ้ามาจากตัวแปร ดู `ui.md`

**ไม่ต้องแก้เมื่อ:**
- ตัวละครอ่านเวลาจากเอกสารหรือหน้าจอ หรือเป็นทหารที่พูดเวลาแบบ 24 ชั่วโมง

### LT10 ความสุภาพไม่ตรงระดับ

**ทำไมดูเป็นงานแปล:** please แปลเป็น "กรุณา" ทุกครั้ง could you แปลเป็น "คุณช่วย...ได้ไหม" ภาษาไทยบอกความสุภาพด้วยคำลงท้ายและคำอย่าง "หน่อย" "ช่วย" "รบกวน"

**ต้นฉบับ:**
> Could you please pass me the salt?

**แปลแข็ง:**
> คุณกรุณาช่วยส่งเกลือให้ฉันได้ไหม

**แปลดี:**
> ส่งเกลือให้หน่อยสิ / ขอเกลือหน่อยครับ

**ไม่ต้องแก้เมื่อ:**
- ป้ายประกาศหรือข้อความทางการ ที่คนไทยก็ใช้ "กรุณา" เช่น "กรุณาปิดเสียงโทรศัพท์"

### LT11 ทับศัพท์หรือปล่อยอังกฤษไม่เหมาะ

**ทำไมดูเป็นงานแปล:** บางงานทับศัพท์ทุกคำจนคนทั่วไปไม่เข้าใจ บางงานแปลคำที่คนไทยใช้ทับศัพท์กันหมดแล้ว จนฟังแปลก ดูเพิ่มที่ TH19

**หลักเลือก:**
1. อภิธานศัพท์ของผู้ใช้มาก่อน
2. คำที่คนไทยกลุ่มเป้าหมายใช้ทับศัพท์จนเป็นปกติ ให้ทับศัพท์ เช่น แอป ไลก์ แชร์ เลเวล สกิล
3. คำที่มีคำไทยใช้กันทั่วไป ให้ใช้คำไทย เช่น settings = การตั้งค่า, password = รหัสผ่าน
4. ทับศัพท์ให้สะกดตามหลักราชบัณฑิตยสถาน ดู `glossary.md`
5. ชื่อแบรนด์ ชื่อแอป ชื่อรุ่น คงเป็นอังกฤษ เว้นแต่แบรนด์นั้นมีชื่อไทยที่ใช้เป็นทางการ

**ไม่ต้องแก้เมื่อ:**
- งานสำหรับกลุ่มเฉพาะที่ใช้ศัพท์อังกฤษกันอยู่แล้ว เช่น เครื่องมือของนักพัฒนา

### LT12 แปลครบทุกคำจนยาว

**ทำไมดูเป็นงานแปล:** really, actually, just, literally, a, the, s ของพหูพจน์ ถูกแปลทุกตัว ได้ประโยคยาวที่มี "จริงๆ" "จริงๆ แล้ว" "แค่" "หนึ่ง" "หลายๆ" เต็มไปหมด

**ต้นฉบับ:**
> I just really need a coffee right now.

**แปลแข็ง:**
> ฉันแค่ต้องการกาแฟหนึ่งแก้วจริงๆ ในตอนนี้

**แปลดี:**
> ขอกาแฟสักแก้วเถอะ

**ไม่ต้องแก้เมื่อ:**
- คำนั้นสำคัญต่อความหมาย เช่น "I just got here" = "เพิ่งมาถึง" ต้องมี "เพิ่ง"
- จำนวนสำคัญ เช่น "one more chance" = "อีกครั้งเดียว"
