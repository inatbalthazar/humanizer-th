# เกม

เกมหนึ่งเกมมีข้อความหลายแบบ แต่ละแบบต้องแปลต่างกัน บทพูดต้องมีชีวิต ชื่อไอเทมต้องสั้นและจำง่าย เมนูต้องชัดแบบ UI ทั่วไป และทุกอย่างต้องใช้คำเดียวกันทั้งเกม

## 1. ประเภทข้อความ

| ประเภท | แปลอย่างไร | ดูเพิ่ม |
|---|---|---|
| บทพูดในเนื้อเรื่อง | ตามตัวละครและความสัมพันธ์ | `characters.md` |
| เสียงตะโกนสั้น (bark) เช่น "Reloading!" "Enemy spotted!" | สั้นมาก พูดได้ในจังหวะต่อสู้ และต้องใช้ได้ในหลายสถานการณ์ | หัวข้อ 6 |
| เควสต์และภารกิจ | ชื่อเควสต์สั้น คำอธิบายบอกชัดว่าต้องทำอะไร | หัวข้อ 5 |
| ชื่อไอเทม สกิล สถานที่ | ตามหลักชื่อเฉพาะ | หัวข้อ 3–4 |
| คำอธิบายไอเทม | ค่าตัวเลขชัด flavor text ใช้ภาษาวรรณกรรมได้ | หัวข้อ 4 |
| เมนู ตั้งค่า ปุ่ม | ตามหลัก UI | `ui.md` |
| สอนเล่น (tutorial) | คำสั่งสั้น ชื่อปุ่มตรงกับเมนูจริง | หัวข้อ 5 |
| ความสำเร็จ (achievement) | ชื่อติดหู คำอธิบายบอกเงื่อนไขชัด | |
| ข้อความระหว่างโหลด | ประโยคเดียว อ่านจบก่อนโหลดเสร็จ | |

## 2. ผู้เล่น

ผู้เล่นอาจเป็นผู้ชาย ผู้หญิง หรือไม่ระบุ ข้อความที่ตัวละครพูดกับผู้เล่น หรือผู้เล่นพูดเอง ต้องระวังเรื่องเพศ

- **เกมไม่มีตัวแปรเพศ:** ใช้คำที่ไม่ระบุเพศ ละประธาน หรือใช้ "เรา" แทนตัวผู้เล่น ไม่ใส่ "ครับ" "ค่ะ" ในประโยคที่ผู้เล่นพูด
- **เกมมีตัวแปรเพศ:** ถ้ารูปแบบไฟล์รองรับ เช่น ICU `{gender, select, male {...} female {...} other {...}}` ให้แปลแยกแต่ละแบบ
- **ตัวละครเรียกผู้เล่น:** เกมแฟนตาซีใช้ "ท่าน" "เจ้า" ได้โดยไม่ระบุเพศ เกมยุคปัจจุบันใช้ "คุณ" หรือชื่อตัวแปร เช่น `[PlayerName]`

## 3. ชื่อเฉพาะ

ตัดสินครั้งเดียวต่อชื่อ แล้วใส่ในอภิธานศัพท์ของงาน

| ชนิดชื่อ | ค่าเริ่มต้น | ตัวอย่าง |
|---|---|---|
| ชื่อคนที่แต่งขึ้น | ทับศัพท์ | Elara = เอลารา |
| ชื่อสถานที่ที่เป็นคำแต่ง | ทับศัพท์ | Valoria = วาโลเรีย |
| ชื่อสถานที่ที่มีความหมาย | แปล | Whispering Woods = ป่ากระซิบ |
| ชื่อไอเทมและสกิล | แปล | Healing Potion = ยาฟื้นพลัง |
| ชื่อเกม ชื่อแบรนด์ ชื่อโหมดที่ใช้ในการตลาด | คงอังกฤษ หรือตามที่ผู้ใช้กำหนด | |
| ชื่อที่ผู้เล่นไทยเรียกเป็นอังกฤษกันทั่วไป | ทับศัพท์หรือคงอังกฤษ | Boss = บอส |

ทับศัพท์ตามเสียงที่ผู้เล่นจะพูด และสะกดตามหลักราชบัณฑิตยสถานเมื่อไม่ขัดกับที่ผู้เล่นใช้จริง ถ้าผู้ใช้มีชื่อที่ทับศัพท์ไว้แล้ว ใช้ตามนั้น

## 4. ชื่อไอเทม สกิล และคำอธิบาย

- **ชื่อสั้น** ไม่เกินที่ช่องในเกมแสดงได้ ส่วนใหญ่ 2–4 คำ
- **เลี่ยง "แห่ง" ต่อกันยาว** "ดาบแห่งราชันย์แห่งความมืด" เป็น "ดาบราชันย์มืด"
- **ชุดชื่อที่มีระดับต้องตรงกันทั้งชุด** เช่น ระดับความหายาก Common, Rare, Epic, Legendary ใช้ ธรรมดา, หายาก, มหากาพย์, ตำนาน ทั้งเกม
- **คำอธิบายค่าตัวเลข** ต้องชัดและสั้น ตัวเลขและตัวแปรอยู่ครบ เช่น "Deals {0} fire damage over 3 seconds" เป็น "สร้างความเสียหายไฟ {0} หน่วยใน 3 วินาที"
- **flavor text** (ข้อความเล่าเรื่องของไอเทม) ใช้ภาษาวรรณกรรมได้ แต่ยังต้องไม่ฟังเหมือนแปล

## 5. เควสต์และสอนเล่น

- ชื่อเควสต์: สั้น ชวนเล่น ไม่ต้องแปลตรงทุกคำ
- คำอธิบายเควสต์: บอกเป้าหมายให้ชัด ผู้เล่นต้องรู้ว่าไปที่ไหน ทำอะไร
- เป้าหมายย่อย: ขึ้นต้นด้วยคำกริยา เช่น "Collect 5 herbs (0/5)" เป็น "เก็บสมุนไพร 5 ต้น (0/5)"
- สอนเล่น: ชื่อปุ่มและชื่อเมนูต้องตรงกับที่แปลไว้ใน UI ทุกตัวอักษร "Press [A] to jump" เป็น "กด [A] เพื่อกระโดด" หรือ "กด [A] กระโดด"

## 6. เสียงตะโกนและบทสั้น

bark เป็นบรรทัดที่เกมสุ่มเล่นได้หลายสถานการณ์ และมักไม่มีบริบท

- แปลให้ใช้ได้ทุกสถานการณ์ที่บรรทัดนั้นอาจถูกเล่น
- สั้นกว่าหรือเท่าต้นฉบับ ถ้ามีเสียงพากย์ ให้พูดจบในเวลาเท่าต้นฉบับ
- ใช้คำที่คนไทยตะโกนจริง เช่น "Enemy spotted!" เป็น "เจอศัตรู" "Reloading!" เป็น "รีโหลด" "Cover me!" เป็น "คุ้มกันที"

## 7. ข้อความที่เกมต่อกันเอง

ถ้าเห็นว่าข้อความถูกต่อกันด้วยโค้ด เช่น key หนึ่งเป็น "You obtained " อีก key เป็นชื่อไอเทม ลำดับคำไทยอาจไม่เข้ากัน

- แปลให้ต่อกันแล้วยังอ่านได้ เช่น "ได้รับ " + ชื่อไอเทม
- ถ้าต่อกันแล้วอ่านไม่ได้จริงๆ ให้แจ้งในบันทึกว่าควรรวมเป็นข้อความเดียวที่มีตัวแปร

## 8. เรตอายุ

ความรุนแรง คำหยาบ และเนื้อหาทางเพศ ต้องแรงเท่าต้นฉบับ (ข้อห้ามข้อ 3 ใน SKILL.md) ถ้าเกมมีเรตอายุต่ำ แต่ต้นฉบับมีคำแรง ให้แปลตามต้นฉบับแล้วแจ้งในบันทึก ไม่ปรับเอง
