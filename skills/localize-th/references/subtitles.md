# ซับไตเติลและบทพากย์

ซับไตเติลต่างจากการแปลทั่วไปตรงที่คนดูมีเวลาอ่านจำกัด และต้องดูภาพไปด้วย ซับที่ดีจึงสั้น อ่านทันในครั้งเดียว และแบ่งบรรทัดตรงที่คนอ่านหยุดเองตามธรรมชาติ

## 1. ค่าเริ่มต้น

ใช้ตัวเลขชุดนี้เมื่อผู้ใช้ไม่ได้ให้ style guide มา ถ้าผู้ใช้หรือแพลตฟอร์มมีข้อกำหนดของตัวเอง ให้ใช้ตามนั้นแทน

| เรื่อง | ค่าเริ่มต้น |
|---|---|
| ความยาวต่อบรรทัด | ไม่เกิน 35 ตัวอักษร |
| จำนวนบรรทัด | ไม่เกิน 2 บรรทัดต่อบล็อก |
| ความเร็วการอ่าน | ไม่เกินประมาณ 20 ตัวอักษรต่อวินาที (รายการเด็ก ประมาณ 17) |
| เวลาและเลขบล็อก | เหมือนต้นฉบับทุกบล็อก |

ตัวเลขความยาวบรรทัดและความเร็วการอ่านอิงจากแนวทางซับภาษาไทยของ Netflix (Thai Timed Text Style Guide) แพลตฟอร์มอื่นอาจต่างออกไป

### วิธีนับตัวอักษร

- นับพยัญชนะ สระที่อยู่ในบรรทัด ตัวเลข เครื่องหมาย และช่องว่าง
- **ไม่นับ** วรรณยุกต์ ( ่ ้ ๊ ๋ ) สระบนและสระล่าง ( ั ิ ี ึ ื ุ ู ็ ) การันต์ ( ์ ) เพราะไม่กินที่ในแนวนอน
- "ำ" "ๆ" "ฯ" นับเป็น 1 ตัว

ตัวอย่าง: "ไม่เป็นไรหรอก" นับได้ 11 ตัว คือ ไ ม เ ป น ไ ร ห ร อ ก ส่วน ่ กับ ็ ไม่นับ ถ้าไม่แน่ใจให้นับด้วยสคริปต์ `scripts/check_translation.py`

### ความเร็วการอ่าน

ความเร็วการอ่าน = จำนวนตัวอักษรทั้งบล็อก ÷ ระยะเวลาที่บล็อกขึ้นจอ (วินาที)

บล็อกยาว 2 วินาทีจึงใส่ได้ประมาณ 40 ตัวอักษร ถ้าคำแปลยาวกว่านั้น ต้องย่อ

## 2. การแบ่งบรรทัด

ภาษาไทยไม่เว้นวรรคระหว่างคำ จึงต้องระวังเป็นพิเศษ

1. **ถ้าพอดีบรรทัดเดียว ให้ใช้บรรทัดเดียว** อย่าแบ่งเพราะเคยชิน
2. **แบ่งที่ขอบคำเสมอ** ห้ามตัดกลางคำ ห้ามแยกชื่อคน ห้ามแยกตัวเลขออกจากหน่วย
3. **แบ่งตรงจุดหยุดหายใจ** เช่น ระหว่างประโยคย่อย หรือก่อนคำเชื่อมอย่าง "แต่" "เพราะ" "แล้ว"
4. **คำลงท้ายอยู่กับคำที่มันลงท้าย** อย่าให้ "ครับ" "นะ" "ล่ะ" ขึ้นบรรทัดใหม่โดดๆ
5. **สองบรรทัดยาวใกล้กัน** ดีกว่าบรรทัดหนึ่งยาวมากอีกบรรทัดสั้นมาก แต่ความหมายมาก่อนความสวย

**แบ่งไม่ดี:**
```
ฉันบอกแกแล้วว่าอย่าไปยุ่งกับ
พวกนั้น
```

**แบ่งดี:**
```
บอกแล้วไง
ว่าอย่าไปยุ่งกับพวกนั้น
```

## 3. เครื่องหมาย

| เครื่องหมาย | ใช้อย่างไร |
|---|---|
| จุด (.) | ไม่ใส่ท้ายประโยค |
| จุลภาค (,) | ไม่ใช้ เว้นวรรคแทน |
| ? | ใส่ได้กับคำถามที่ไม่มีคำถามอยู่ในประโยค หรือเมื่อน้ำเสียงเป็นคำถามจริงๆ ถ้ามี "ไหม" "อะไร" "เหรอ" อยู่แล้วไม่ต้องใส่ก็ได้ |
| ! | ไม่ใส่เป็นค่าเริ่มต้น ใช้คำลงท้ายและคำอุทานแสดงอารมณ์แทน (TH29) ใส่เมื่อ style guide ของผู้ใช้กำหนด |
| ... | ประโยคค้าง ลากเสียง หรือต่อไปบล็อกถัดไป ใช้ให้น้อย |
| - | ขึ้นต้นบรรทัดเมื่อบล็อกเดียวมีคนพูดสองคน คนละบรรทัด ใช้รูปแบบเดียวกับต้นฉบับ |
| ๆ | เว้นวรรคหลัง ๆ เมื่อมีคำต่อ |
| "..." | คำพูดที่ยกมา ชื่อเพลง ชื่อหนังสือ |

ตัวเอียง (`<i>` ใน SRT และ VTT, `{\i1}...{\i0}` ใน ASS) ใช้ตามต้นฉบับ เช่น เสียงจากนอกจอ เสียงในโทรศัพท์ เสียงในความคิด และเพลง

## 4. การย่อ

ซับไม่ต้องแปลทุกคำ แต่ต้องได้ใจความครบ ย่อตามลำดับนี้

1. คำเสริมที่ไม่มีความหมาย: um, uh, you know, like, I mean
2. คำซ้ำ: "No, no, no" เป็น "ไม่ๆ" หรือ "ไม่"
3. ชื่อที่เรียกซ้ำ เมื่อเห็นอยู่แล้วว่าพูดกับใคร
4. สรรพนาม (LT01) และคำแปลครบทุกคำ (LT12)
5. ประโยคซ้อน แยกให้สั้นลงหรือรวมใจความ

**ห้ามตัด:** ข้อมูลที่เรื่องใช้ต่อ ชื่อ ตัวเลข คำปฏิเสธ มุกที่เรื่องเล่นต่อ และคำที่บอกอารมณ์หลักของฉาก

ถ้าย่อจนสุดแล้วยังยาวเกินเวลา ให้คงใจความไว้ แล้วระบุเลขบล็อกในบันทึกการแปล ห้ามแก้เวลาเองเพื่อให้พอดี

## 5. เวลาและบล็อก

- ห้ามเปลี่ยนเวลา ห้ามรวมหรือแยกบล็อก เว้นแต่ผู้ใช้อนุญาต
- ประโยคที่ต่อข้ามบล็อก ให้แต่ละบล็อกอ่านได้เป็นช่วงที่มีความหมาย ไม่ใช่ตัดกลางวลี
- ถ้าลำดับคำไทยต่างจากอังกฤษจนต้องสลับเนื้อหาระหว่างบล็อก ทำได้เมื่อภาพไม่ขัด เช่น ไม่มีคนพูดชื่อในบล็อกแรกแล้วซับไปขึ้นชื่อในบล็อกที่สอง

## 6. ซับสำหรับคนหูหนวกหรือได้ยินไม่ชัด (SDH)

ใช้เฉพาะเมื่อต้นฉบับเป็น SDH

- เสียงประกอบในวงเล็บเหลี่ยม เช่น `[เสียงประตูปิด]` `[หัวเราะ]` `[ดนตรีตื่นเต้น]`
- ชื่อผู้พูดเมื่อไม่เห็นหน้า เช่น `มายา: กลับมาแล้วเหรอ`
- คงเนื้อหาให้ใกล้ต้นฉบับที่สุด ย่อเฉพาะเมื่อความเร็วการอ่านเกินมาก

## 7. ป้ายและตัวหนังสือบนจอ

แปลเมื่อเกี่ยวกับเรื่อง เช่น ข้อความในโทรศัพท์ ป้ายชื่อร้านที่เรื่องพูดถึง ใช้รูปแบบตามที่ผู้ใช้กำหนด ถ้าไม่ได้กำหนด ให้ใส่ในบล็อกที่ตรงกับเวลาที่ตัวหนังสือขึ้น และบอกในบันทึก

## 8. บทพากย์ (dubbing)

บทพากย์คือบทให้นักพากย์หรือเสียง AI อ่าน ไม่ใช่ให้คนดูอ่าน กฎจึงต่างจากซับ

- **ความยาวต้องใกล้ต้นฉบับ** ความยาวที่พูดต้องพอดีกับช่วงที่ตัวละครขยับปาก นับพยางค์เทียบกับต้นฉบับ ภาษาไทยมักใช้พยางค์มากกว่าอังกฤษสำหรับใจความเดียวกัน จึงต้องเลือกคำสั้น
- **ไม่ต้องย่อแบบซับ** คำเสริมอย่าง "อืม" "เอ่อ" ใส่ได้ถ้าตัวละครทำท่าแบบนั้น
- **ช่วงที่เห็นปากชัด** (ระยะใกล้) ให้จังหวะการหยุดตรงกับต้นฉบับ ช่วงที่หันหลังหรือไกล ยืดหยุ่นได้
- **เขียนให้อ่านออกเสียงได้ทันที** ตัวเลขเขียนเป็นคำ ("สามร้อยบาท" ไม่ใช่ "300 บาท") ตัวย่อเขียนเต็ม คำอังกฤษที่ต้องพูดเขียนเป็นภาษาไทยตามเสียงที่ต้องการ
- **เสียงพากย์ AI** ถ้าผู้ใช้จะเอาบทไปให้ AI อ่าน ใช้ skill `script-th` ช่วยเกลาบทให้ AI อ่านถูกได้อีกขั้น
- ส่งในรูปแบบที่ผู้ใช้ให้มา ถ้าเป็นไฟล์ซับที่ใช้เป็นบทพากย์ ให้คงเวลาไว้เหมือนเดิม
