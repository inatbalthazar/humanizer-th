# humanizer-th

![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg) ![version](https://img.shields.io/badge/version-0.1.1-green.svg)

Skill ของ Claude สำหรับเกลาภาษาไทยที่อ่านแล้วรู้เลยว่า AI เขียน ให้กลับมาอ่านเหมือนคนไทยเขียนเอง

[English](README.en.md)

## ตัวอย่าง

ข้อความ LINE ขอให้รุ่นพี่ที่ทำงานเข้ากะแทน

**ก่อน**

> สวัสดีครับพี่เมย์ ผมหวังว่าพี่จะสบายดีนะครับ ผมต้องการที่จะขอความช่วยเหลือจากพี่ในเรื่องหนึ่งครับ เนื่องจากในวันเสาร์ที่ 7 นี้ ผมมีความจำเป็นต้องเดินทางกลับต่างจังหวัดเพื่อไปร่วมงานบวชของน้องชาย ดังนั้น ผมจึงอยากสอบถามว่าพี่จะสามารถช่วยเข้ากะแทนผมในช่วงเวลา 13.00–21.00 น. ได้หรือไม่ครับ ทั้งนี้ ผมยินดีที่จะเข้ากะแทนพี่ในวันอื่นเป็นการตอบแทนครับ ขอบคุณพี่มากๆ สำหรับการพิจารณาครับ 🙏

**หลัง**

> พี่เมย์ครับ ขอรบกวนหน่อย เสาร์ที่ 7 นี้ผมต้องกลับต่างจังหวัดไปงานบวชน้องชาย พี่พอจะเข้ากะแทนผมช่วง 13.00–21.00 น. ได้ไหมครับ เดี๋ยวผมเข้ากะแทนพี่วันอื่นคืนให้ ขอบคุณมากครับ

ภาษาหนังสือ คำฟุ่มเฟือย และอีโมจิหายไป แต่วันที่ เวลา ชื่อ และ "ครับ" ของคนเขียนยังอยู่ครบ ดูตัวอย่างอื่นได้ใน [examples/](examples/)

## ใช้ทำอะไร

สั่งได้ 3 แบบ

| แบบ | พิมพ์ประมาณนี้ | ได้อะไร |
|---|---|---|
| ตรวจ | "ตรวจหน่อยว่าตรงไหนดูเป็น AI" | บอกว่าตรงไหนดูเป็น AI เพราะอะไร ยังไม่แก้ให้ |
| เขียนใหม่ | "เกลาให้หน่อย" | ข้อความใหม่ทั้งชิ้น พร้อมสรุปว่าแก้อะไรไป ถ้าไม่บอกว่าเอาแบบไหนจะใช้แบบนี้ |
| แก้เฉพาะจุด | "แก้แค่ตรงที่แข็งๆ พอ" | แก้เฉพาะคำหรือประโยคที่มีปัญหา โครงเดิมไม่เปลี่ยน |

ระดับภาษาเรียกตามที่เรียนกันในวิชาภาษาไทย

| ระดับ | ใช้กับ |
|---|---|
| กันเอง | แชตกับเพื่อนหรือคนสนิท |
| ไม่เป็นทางการ | โพสต์ บล็อก แชตกับหัวหน้าหรือเพื่อนร่วมงาน |
| กึ่งทางการ | อีเมลงาน ข้อความถึงลูกค้า |
| ทางการ | รายงาน หนังสือราชการ |

ถ้าไม่บอกระดับ skill จะดูจากเนื้อหาเอง แล้วบอกว่าเลือกระดับไหน

**สิ่งที่ skill ไม่แตะ**

- ตัวเลข วันที่ ราคา ชื่อคน ชื่อแบรนด์
- คำพูดของคนอื่นที่ยกมา ลิงก์ โค้ด
- "ครับ" หรือ "ค่ะ" ของคนเขียน

skill จะไม่เติมข้อมูลที่ต้นฉบับไม่มี และถ้าข้อความอ่านดีอยู่แล้วก็จะบอกตรงๆ ว่าไม่ต้องแก้

## ติดตั้ง

### Claude.ai

1. โหลด `humanizer-th.zip` จากหน้า [Releases](https://github.com/inatbalthazar/humanizer-th/releases)
2. ไปที่ Settings → Capabilities → Skills แล้วอัปโหลดไฟล์ zip
3. เปิดใช้ skill แล้วเริ่มใช้ได้เลย

### Claude Code

คัดลอกโฟลเดอร์ skill ไปไว้ที่ `~/.claude/skills/`

```bash
git clone https://github.com/inatbalthazar/humanizer-th.git
cp -r humanizer-th/skills/humanizer-th ~/.claude/skills/
```

## วิธีใช้

วางข้อความ แล้วบอกว่าจะเอาไปใช้ที่ไหน ยิ่งบอกชัด ระดับภาษายิ่งตรง

```text
เกลาให้หน่อย จะโพสต์เฟซบุ๊กเพจร้าน
[วางข้อความ]
```

```text
ตรวจหน่อยว่าตรงไหนดูเป็น AI
[วางข้อความ]
```

```text
แก้แค่ตรงที่แข็งๆ พอ อย่าเปลี่ยนโครง จะส่งอีเมลหาลูกค้า
[วางข้อความ]
```

คำตอบแบบเขียนใหม่จะออกมาหน้าตาแบบนี้

```text
[ข้อความที่แก้แล้ว]

---
ระดับภาษา: กึ่งทางการ
สิ่งที่เปลี่ยน:
- ตัด "ได้ทำการ" (TH03) 2 จุด
- เปลี่ยนประโยคแปลตรง "ทำให้แน่ใจว่า" เป็น "ตรวจให้ดีว่า" (TH07)
```

## ตรวจอะไรบ้าง

ตอนนี้มี 29 รูปแบบ แบ่งเป็น 5 หมวด

| หมวด | ที่เจอบ่อย |
|---|---|
| ประโยค | "ได้ทำการ" "ถูกพัฒนาโดย" ประโยคที่ต่อด้วย "ซึ่ง" ยาวเป็นพรวน "ทำให้แน่ใจว่า" |
| คำ | "ทำการตรวจสอบ" "ยกระดับ" "อย่างมีประสิทธิภาพ" "สามารถ...ได้" |
| น้ำเสียงและระดับภาษา | เรียก "คุณ" ทุกประโยค ครับกับค่ะสลับกัน ภาษาราชการใน LINE |
| โครงและรูปแบบ | เปิดด้วย "ในยุคดิจิทัลปัจจุบัน" มีคำเชื่อมทุกประโยค ปิดด้วย "หวังว่าบทความนี้จะเป็นประโยชน์" |
| เครื่องหมาย | จุลภาคแบบอังกฤษ จุดท้ายประโยค อีโมจิ และ "!" |

ส่วนใหญ่คือสิ่งที่วิชาภาษาไทยเรียกว่า**ประโยคฟุ่มเฟือย**กับ**สำนวนต่างประเทศ** ที่เหลือเป็นนิสัยของแชตบอต เช่น ใส่อีโมจิท้ายข้อความ หรือขึ้นต้นด้วย "แน่นอนค่ะ"

รายละเอียดของแต่ละรูปแบบ และกรณีที่ไม่ต้องแก้ อยู่ใน [patterns.md](skills/humanizer-th/references/patterns.md) (มีแหล่งอ้างอิงท้ายไฟล์) เรื่องระดับภาษากับคำลงท้ายอยู่ใน [registers.md](skills/humanizer-th/references/registers.md) ส่วนตารางคำที่ใช้แทนกันได้อยู่ใน [word-swaps.md](skills/humanizer-th/references/word-swaps.md)

## ไม่ได้มีไว้หลบ AI detector

skill นี้ทำมาให้คนอ่านอ่านง่ายขึ้น ไม่ได้ทำมาหลบโปรแกรมตรวจ AI และจะไม่แกล้งใส่คำผิดให้ดูเหมือนคนเขียน

งานแปลจากภาษาอังกฤษก็ไม่ได้ทำ ถ้ามีข้อความภาษาอังกฤษ ให้แปลก่อนแล้วค่อยเอามาเกลา

## ข้อจำกัด

- ใช้กับภาษาไทยอย่างเดียว
- Claude ทำตามคำแนะนำในไฟล์ ไม่ได้รันเป็นโปรแกรม ผลแต่ละครั้งจึงไม่เหมือนกันเป๊ะ ควรอ่านทวนก่อนเอาไปใช้
- บางรูปแบบเป็นเรื่องรสนิยม ทุกรูปแบบจึงเขียนไว้ด้วยว่าตอนไหนไม่ต้องแก้
- ยังไม่มีชุดทดสอบอัตโนมัติ
