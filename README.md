# humanizer-th

![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg) ![version](https://img.shields.io/badge/version-0.4.0-green.svg)

ชุด skill ภาษาไทยสำหรับ AI แปลซับหนัง เกม แอป และเว็บไซต์เป็นภาษาไทยที่อ่านแล้วไม่รู้ว่าแปลมา เขียนบทละครสั้นและบทพากย์สำหรับวิดีโอ AI และเกลาข้อความที่ AI เขียนให้อ่านเหมือนคนไทยเขียนเอง

ใช้ได้กับ Claude, ChatGPT, Gemini, Codex, GitHub Copilot, Cursor และ AI ตัวอื่นที่รองรับ [Agent Skills](https://agentskills.io) ตัวที่ไม่รองรับก็ใช้ได้ โดยวางไฟล์รวมเป็นคำสั่งแทน

## แปลซับ เกม แอป และเว็บไซต์ (localize-th)

งานแปลส่วนใหญ่ที่ได้จาก AI ถูกทุกคำแต่คนไทยอ่านแล้วรู้ทันทีว่าแปลมา และบางครั้งทำไฟล์พังด้วย เช่น เวลาในซับเลื่อน หรือตัวแปรในแอปหาย

| ต้นฉบับ | แปลแบบทั่วไป | localize-th |
|---|---|---|
| Oh no. (ซับ) | โอ้ไม่ | ซวยแล้ว |
| What do you think? (ซับ) | คุณคิดว่าอย่างไร | คิดว่าไงล่ะ |
| Payment failed. (แอป) | การชำระเงินล้มเหลว | ชำระเงินไม่สำเร็จ |
| Your cart (แอป) | ตะกร้าของคุณ | ตะกร้า |
| No haggling, my back can't take it. (เกม) | ห้ามต่อรอง หลังของฉันรับไม่ไหว | ห้ามต่อนะ ข้าแก่แล้ว เถียงไม่ไหว |

**สิ่งที่ skill คุมให้**

- **ไฟล์ไม่พัง:** เวลาและเลขบล็อกในซับ key ตัวแปรอย่าง `{name}` `%s` `[PlayerName]` และแท็กต่างๆ อยู่ครบเหมือนต้นฉบับ
- **ซับอ่านทัน:** บรรทัดละไม่เกิน 35 ตัวอักษร ไม่เกิน 2 บรรทัด ความเร็วการอ่านไม่เกิน 20 ตัวอักษรต่อวินาที และตัดบรรทัดที่ขอบคำ ตามแนวทางซับไทยของ Netflix เปลี่ยนตัวเลขได้ถ้ามี style guide ของตัวเอง
- **ตัวละครพูดเหมือนคน:** เลือกสรรพนามและคำลงท้ายตามความสัมพันธ์ เช่น พี่น้องใช้ "พี่" กับ "แก" เกมแฟนตาซีใช้ "ข้า" กับ "เจ้า" และใช้แบบเดียวกันตลอดเรื่อง
- **ศัพท์ตรงกันทั้งงาน:** ใช้อภิธานศัพท์ของผู้ใช้ ถ้าไม่มีก็ใช้คำมาตรฐานที่คนไทยเห็นในแอปทั่วไป และสะกดคำทับศัพท์ตามราชบัณฑิตยสถาน
- **บทพากย์:** ความยาวที่พูดใกล้ต้นฉบับ และเขียนให้อ่านออกเสียงได้ทันที

**ไฟล์ที่รองรับ:** SRT, VTT, ASS, JSON, ARB, PO, XLIFF, iOS `.strings` `.stringsdict` `.xcstrings`, Android `strings.xml`, YAML, CSV และข้อความที่วางมาในแชต

**ตรวจไฟล์ด้วยสคริปต์:** ใน skill มี `check_translation.py` เทียบไฟล์ที่แปลกับต้นฉบับ แจ้งเวลาที่เปลี่ยน key หรือตัวแปรที่หาย บรรทัดซับที่ยาวเกิน และความเร็วการอ่านที่เกิน AI ที่รันคำสั่งได้ (เช่น Claude Code, Codex) จะรันให้เอง หรือจะรันเองก็ได้

```bash
python3 skills/localize-th/scripts/check_translation.py en.srt th.srt
```

ตัวอย่างเต็ม: [ซับ SRT](examples/localize-th/01-subtitle-srt.md) / [แอป JSON](examples/localize-th/02-app-ui-json.md) / [เกม CSV](examples/localize-th/03-game-dialogue-csv.md) / [เมนูเกมสำหรับคนที่อ่านไทยไม่ออก](examples/localize-th/04-english-speaker.md)

## บทละครสั้น AI และบทพากย์ (script-th)

ใช้กับละครสั้นแนวตั้งที่สร้างด้วยเว็บสร้างวิดีโอ AI และงานที่ให้ AI พากย์เสียงไทย

**ก่อน** (บทที่ AI เขียน)

```text
นิว: ต้น ฉันรู้สึกผิดหวังและเสียใจมากที่คุณโกหกฉันเรื่องที่คุณไปเชียงใหม่
ต้น: นิว ผมขอโทษครับ ผมไม่ได้มีเจตนาที่จะทำให้คุณรู้สึกแย่ ซึ่งผมมีเหตุผลที่ผมไม่สามารถบอกคุณได้ในตอนนี้ครับ
```

**หลัง**

```text
นิว: เชียงใหม่สนุกมั้ย
ต้น: (ชะงัก) ขอโทษ มีเหตุผลจริงๆ แต่ตอนนี้ยังบอกไม่ได้
```

**สั่งได้ 4 แบบ**

| แบบ | ได้อะไร |
|---|---|
| เขียนบท | ตารางตัวละคร บทแบ่งฉาก เปิดเรื่องให้ดึงคนดูใน 3 วินาที จบตอนแบบค้างให้อยากดูต่อ |
| เกลาบท | บทเดิมที่พูดเหมือนคนจริงขึ้น เรื่องและข้อมูลไม่เปลี่ยน |
| ทำพรอมต์ | พรอมต์ทีละช็อตที่คัดลอกไปวางได้ทันที บทพูดยาวพอดีคลิป หน้าตาตัวละครเหมือนกันทุกช็อต |
| เตรียมบทพากย์ | บทที่เสียง AI อ่านถูก ตัวเลขเขียนเป็นคำ คำอ่านยากเขียนตามเสียง มีทิศทางเสียงทุกบรรทัด |

skill จะถามว่าจะใส่เสียงแบบไหน ให้โมเดลวิดีโอพูดเอง ใช้เสียง AI แยกแล้วทำลิปซิงก์ หรือใช้เสียงบรรยายกับซับ เพราะเว็บสร้างวิดีโอหลายตัวยังพูดภาษาไทยได้ไม่ดี

ตัวอย่างเต็ม: [เขียนบทจากไอเดีย](examples/script-th/01-write-short-drama.md) / [เกลาบทที่ AI เขียน](examples/script-th/02-polish-ai-script.md) / [พรอมต์และบทพากย์](examples/script-th/03-shot-prompts-and-voice.md)

## เกลาข้อความที่ AI เขียน (humanizer-th)

ข้อความ LINE ขอให้รุ่นพี่ที่ทำงานเข้ากะแทน

**ก่อน**

> สวัสดีครับพี่เมย์ ผมหวังว่าพี่จะสบายดีนะครับ ผมต้องการที่จะขอความช่วยเหลือจากพี่ในเรื่องหนึ่งครับ เนื่องจากในวันเสาร์ที่ 7 นี้ ผมมีความจำเป็นต้องเดินทางกลับต่างจังหวัดเพื่อไปร่วมงานบวชของน้องชาย ดังนั้น ผมจึงอยากสอบถามว่าพี่จะสามารถช่วยเข้ากะแทนผมในช่วงเวลา 13.00–21.00 น. ได้หรือไม่ครับ ทั้งนี้ ผมยินดีที่จะเข้ากะแทนพี่ในวันอื่นเป็นการตอบแทนครับ ขอบคุณพี่มากๆ สำหรับการพิจารณาครับ 🙏

**หลัง**

> พี่เมย์ครับ ขอรบกวนหน่อย เสาร์ที่ 7 นี้ผมต้องกลับต่างจังหวัดไปงานบวชน้องชาย พี่พอจะเข้ากะแทนผมช่วง 13.00–21.00 น. ได้ไหมครับ เดี๋ยวผมเข้ากะแทนพี่วันอื่นคืนให้ ขอบคุณมากครับ

สั่งได้ 4 แบบ คือ **ตรวจ** (บอกว่าตรงไหนดูเป็น AI ยังไม่แก้) **เขียนใหม่** (เกลาทั้งชิ้น) **แก้เฉพาะจุด** (แก้แค่คำที่แข็ง) และ **เลียนสไตล์** (เขียนให้เป็นสำนวนของเราเอง ดูหัวข้อถัดไป) และเลือกระดับภาษาตามที่เรียนในวิชาภาษาไทย คือ กันเอง ไม่เป็นทางการ กึ่งทางการ และทางการ

ตรวจ 29 รูปแบบ ส่วนใหญ่คือสิ่งที่วิชาภาษาไทยเรียกว่า**ประโยคฟุ่มเฟือย**กับ**สำนวนต่างประเทศ** เช่น "ได้ทำการ" "ถูกพัฒนาโดย" "ทำให้แน่ใจว่า" ที่เหลือเป็นนิสัยของแชตบอต เช่น อีโมจิท้ายข้อความ ดูรายละเอียดใน [patterns.md](shared/patterns.md) และตัวอย่างอื่นใน [examples/humanizer-th/](examples/humanizer-th/)

### เขียนให้เป็นสำนวนของเราเอง (เลียนสไตล์)

ข้อความที่เกลาแล้วอาจเป็นธรรมชาติ แต่ยังไม่ใช่เสียงของเรา คนที่อ่านโพสต์เราทุกวันอ่านแล้วรู้สึกว่าไม่ใช่เรา โหมดนี้มีไว้แก้เรื่องนั้น ส่งงานเก่าของตัวเองมา 3 ชิ้นขึ้นไป พร้อมร่างที่ AI เขียน หรือแค่บอกว่าจะเขียนเรื่องอะไร skill จะดูว่าเราเรียกตัวเองว่าอะไร ใส่ "ครับ" ตรงไหน ขึ้นบรรทัดใหม่บ่อยแค่ไหน ชอบเปิดและปิดยังไง เขียนเวลาและราคาแบบไหน แล้วเขียนตามนั้น

**ร่างจาก AI**

```text
📢 ประกาศสำคัญจากทางร้าน 📢

เรียนลูกค้าทุกท่าน ทางร้านขอแจ้งให้ทราบว่า ร้านจะปิดให้บริการเป็นการชั่วคราวในวันจันทร์ที่ 14 และวันอังคารที่ 15 นี้ เนื่องจากเจ้าของร้านจะเดินทางไปเข้าร่วมการอบรมการคั่วกาแฟที่จังหวัดเชียงราย ...
```

**หลังเลียนสไตล์จากโพสต์เก่า 3 ชิ้นของเจ้าของร้าน**

```text
จันทร์ที่ 14 กับอังคารที่ 15 นี้ร้านปิดนะ
ผมไปเรียนคั่วกาแฟที่เชียงราย
กลับมาจะได้คั่วให้ดีกว่าเดิม

ช่วงที่ร้านปิด ใครจะสั่งเมล็ดทักแชตเพจได้ตามปกติ
เดี๋ยวผมส่งให้วันพุธ

ขอโทษที่ต้องปิดไปสองวัน ขอบคุณที่แวะมากันตลอด
พุธที่ 16 เปิดตามเดิม 8 โมงถึงบ่าย 3 ครับ
```

- **เนื้อหามาจากร่างหรือโจทย์เท่านั้น** ไม่หยิบเรื่องจากงานเก่ามาใส่ และไม่แต่งเรื่องเพิ่มให้เหมือนสไตล์ ถ้าสไตล์ต้องใช้ข้อมูลที่ไม่มี จะถามแทน
- **เลียนเท่าที่เห็นจริง** ใช้คำติดปากถี่เท่างานเก่า ไม่ลอกคำที่สะกดผิด และไม่เลียนสำนวนแปลอย่าง "ได้ทำการ" แม้เราจะใช้ประจำ
- **เก็บโปรไฟล์สำนวนไว้ใช้ครั้งหน้าได้** ครั้งต่อไปวางโปรไฟล์แทนงานเก่า แล้วบอกแค่ว่าจะเขียนอะไร
- **ใช้กับงานแปลและงานบทได้ด้วย** ส่งซับตอนก่อนหรือข้อความแอปเวอร์ชันเดิมให้ `localize-th` แปลต่อให้เข้ากัน หรือส่งบทตอนก่อนให้ `script-th` เขียนตอนใหม่ในสไตล์เดิม

ตัวอย่างเต็มพร้อมโปรไฟล์: [examples/humanizer-th/07-match-style.md](examples/humanizer-th/07-match-style.md)

**ทั้งสาม skill ไม่แตะ** ตัวเลข วันที่ ราคา ชื่อคน ชื่อแบรนด์ ลิงก์ โค้ด และ "ครับ" "ค่ะ" ของคนเขียน และไม่เติมข้อมูลที่ต้นฉบับไม่มี

## ติดตั้ง

### Claude Code

พิมพ์ใน Claude Code ได้ทั้งสาม skill

```text
/plugin marketplace add inatbalthazar/humanizer-th
/plugin install humanizer-th@humanizer-th
```

### Codex

```bash
npx skills add inatbalthazar/humanizer-th --global --agent codex
```

### เครื่องมืออื่น

```bash
npx skills add inatbalthazar/humanizer-th --global --agent '*'
```

คำสั่งนี้ติดตั้งให้ทุกเครื่องมือที่ [skills CLI](https://github.com/vercel-labs/skills) รู้จัก เช่น Gemini CLI, GitHub Copilot, Cursor และ Windsurf ถ้าจะใช้แค่ในโปรเจกต์ที่เปิดอยู่ ให้ตัด `--global` ออก ถ้าต้องการแค่บางตัว เติม `--skill localize-th` เป็นต้น

ถ้าเครื่องไม่มี Node.js ใช้สคริปต์นี้แทนได้ (Mac หรือ Linux)

```bash
curl -fsSL https://raw.githubusercontent.com/inatbalthazar/humanizer-th/main/install.sh | bash
```

สคริปต์ติดตั้งทั้งสาม skill ลง `~/.agents/skills/` และลงให้ Claude Code, Gemini CLI, GitHub Copilot ด้วยถ้าเจอในเครื่อง รันซ้ำเพื่ออัปเดตได้ ถ้าต้องการแค่บางตัว ใช้ `| bash -s -- --skill localize-th` ถ้าจะลบ ใช้ `| bash -s -- --uninstall`

### Claude.ai และ Claude Desktop

โหลดไฟล์ zip ของ skill ที่ต้องการจากหน้า [Releases](https://github.com/inatbalthazar/humanizer-th/releases) (`localize-th.zip` `script-th.zip` `humanizer-th.zip`) แล้วอัปโหลดทีละไฟล์ใน Settings → Capabilities → Skills

### ChatGPT, Gemini และ AI ตัวอื่น

โหลดไฟล์รวมของ skill ที่ต้องการจากหน้า [Releases](https://github.com/inatbalthazar/humanizer-th/releases) (`localize-th-prompt.md` `script-th-prompt.md` `humanizer-th-prompt.md`) แต่ละไฟล์รวมทุกอย่างของ skill นั้นไว้ในไฟล์เดียว

- **ChatGPT:** สร้าง GPT หนึ่งตัวต่อหนึ่ง skill อัปโหลดไฟล์ในช่อง Knowledge แล้วพิมพ์ในช่อง Instructions ว่า "ทำตามคำสั่งในไฟล์ [ชื่อไฟล์] ทุกข้อ" (ช่อง Instructions รับได้ 8,000 ตัวอักษร วางทั้งไฟล์ไม่พอ)
- **Gemini:** สร้าง Gem แล้ววางเนื้อหาทั้งไฟล์ในช่องคำสั่ง หรือแนบเป็นไฟล์
- **เรียกผ่าน API:** ใช้เนื้อหาทั้งไฟล์เป็น system prompt
- **แชตทั่วไป:** แนบไฟล์ แล้วพิมพ์ว่าให้ทำตามไฟล์นี้

ไฟล์รวมยาว 59,000–94,000 ตัวอักษร ถ้าเรียกผ่าน API ทุกครั้งจะเสียค่า token พอสมควร เพราะภาษาไทยกิน token มากกว่าภาษาอังกฤษ

### ติดตั้งเอง

คัดลอกโฟลเดอร์ใน `skills/` ไปไว้ในโฟลเดอร์ skill ของเครื่องมือที่ใช้

| เครื่องมือ | ใช้กับทุกโปรเจกต์ | ใช้เฉพาะโปรเจกต์ |
|---|---|---|
| Claude Code | `~/.claude/skills/` | `.claude/skills/` |
| Codex CLI | `~/.agents/skills/` | `.agents/skills/` |
| Gemini CLI | `~/.gemini/skills/` | `.gemini/skills/` |
| GitHub Copilot ใน VS Code | `~/.copilot/skills/` | `.github/skills/` |

เครื่องมือที่ไม่อยู่ในตาราง ส่วนใหญ่อ่าน `.agents/skills/` ได้ ถ้าไม่เจอให้ดูคู่มือของเครื่องมือนั้น

ถ้าจะสร้างไฟล์ zip และไฟล์รวมเองจากโค้ดล่าสุด รัน `bash scripts/build.sh` ไฟล์จะอยู่ในโฟลเดอร์ `dist/`

## สิ่งที่ไม่ทำ

- **ไม่ได้มีไว้หลบ AI detector** ทำมาให้คนอ่านอ่านง่ายขึ้น และจะไม่แกล้งใส่คำผิดให้ดูเหมือนคนเขียน
- **ไม่เขียนในนามคนอื่น** โหมดเลียนสไตล์ใช้กับงานของตัวเอง หรืองานที่เขียนแทนโดยเจ้าตัวรู้ เช่น แอดมินเขียนโพสต์ในนามเจ้าของร้าน ไม่ใช้ปลอมข้อความของคนอื่น
- **ไม่เขียนบทให้คนจริงพูด** เช่น ดารา นักการเมือง เพื่อเอาไปทำวิดีโอ AI เว้นแต่เป็นตัวผู้ใช้เองหรือได้รับอนุญาต และไม่เขียนบทหลอกลวง เช่น ข่าวปลอม คลิปหลอกโอนเงิน
- **แปลจากภาษาอังกฤษเท่านั้น** ยังไม่มีกฎสำหรับต้นฉบับภาษาอื่น

## ข้อจำกัด

- AI ทำตามคำแนะนำในไฟล์ ไม่ได้รันเป็นโปรแกรม ผลแต่ละครั้งจึงไม่เหมือนกันเป๊ะ ควรอ่านทวนก่อนเอาไปใช้ งานแปลที่จะเผยแพร่ควรมีคนไทยอ่านทวนอีกรอบ
- ทดสอบกับ Claude เท่านั้น ตัวอื่นใช้กฎชุดเดียวกัน แต่ผลขึ้นกับว่าโมเดลนั้นเก่งภาษาไทยแค่ไหน
- ยังไม่ได้ลองเอาพรอมต์และบทพากย์ไปใช้กับเว็บสร้างวิดีโอและเสียง AI จริง ตัวเลขพยางค์ต่อวินาทีเป็นค่าประมาณ ให้ลองช็อตแรกแล้วปรับ ดูผลทดสอบใน [tests/manual-test-v0.3.md](tests/manual-test-v0.3.md)
- โหมดเลียนสไตล์ทดสอบกับตัวอย่างที่แต่งขึ้นชุดเดียว ยังไม่ได้ลองกับงานจริงหลายแบบ ดู [tests/manual-test-v0.4.md](tests/manual-test-v0.4.md)
- บางรูปแบบเป็นเรื่องรสนิยม ทุกรูปแบบจึงเขียนไว้ด้วยว่าตอนไหนไม่ต้องแก้
