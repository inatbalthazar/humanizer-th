# humanizer-th

![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg) ![version](https://img.shields.io/badge/version-0.1.0-green.svg)

Skill สำหรับ Claude ที่ช่วยเขียนและแก้ภาษาไทยให้อ่านเป็นธรรมชาติ ตัดร่องรอยการเขียนแบบ AI และสำนวนแปลจากอังกฤษ โดยรักษาความหมาย ข้อเท็จจริง และน้ำเสียงของผู้เขียนไว้

[English README](README.en.md)

## ตัวอย่าง

ข้อความ LINE ถึงรุ่นพี่ที่ทำงานด้วยกันทุกวัน

**ก่อน**

> สวัสดีครับพี่เมย์ ผมหวังว่าพี่จะสบายดีนะครับ ผมต้องการที่จะขอความช่วยเหลือจากพี่ในเรื่องหนึ่งครับ เนื่องจากในวันเสาร์ที่ 7 นี้ ผมมีความจำเป็นต้องเดินทางกลับต่างจังหวัดเพื่อไปร่วมงานบวชของน้องชาย ดังนั้น ผมจึงอยากสอบถามว่าพี่จะสามารถช่วยเข้ากะแทนผมในช่วงเวลา 13.00–21.00 น. ได้หรือไม่ครับ ทั้งนี้ ผมยินดีที่จะเข้ากะแทนพี่ในวันอื่นเป็นการตอบแทนครับ ขอบคุณพี่มากๆ สำหรับการพิจารณาครับ 🙏

**หลัง**

> พี่เมย์ครับ ขอรบกวนหน่อย เสาร์ที่ 7 นี้ผมต้องกลับต่างจังหวัดไปงานบวชน้องชาย พี่พอจะเข้ากะแทนผมช่วง 13.00–21.00 น. ได้ไหมครับ เดี๋ยวผมเข้ากะแทนพี่วันอื่นคืนให้ ขอบคุณมากครับ 🙏

ตัวเลข ชื่อ และคำลงท้าย "ครับ" ของผู้เขียนคงเดิม ข้อความสั้นลงกว่าครึ่ง ดูตัวอย่างอื่นๆ ได้ที่ [examples/](examples/)

## ทำอะไรได้

**3 โหมด**

| โหมด | ตัวอย่างคำสั่ง | ผลลัพธ์ |
|---|---|---|
| `detect` | "ตรวจข้อความนี้ว่าตรงไหนดูเป็น AI" | รายการจุดที่เจอ พร้อมรหัสรูปแบบและเหตุผล ไม่แก้ข้อความ |
| `rewrite` (ค่าเริ่มต้น) | "ช่วยเขียนใหม่ให้เป็นธรรมชาติ" | ข้อความใหม่ทั้งชิ้น + สรุปสิ่งที่เปลี่ยน |
| `edit` | "แก้แค่จุดที่แข็งๆ พอ" | แก้เฉพาะจุด คงโครงสร้างเดิม |

**4 ระดับภาษา:** `chat` (LINE แชต) · `casual` (โพสต์โซเชียล บล็อก) · `professional` (อีเมลงาน ข้อความถึงลูกค้า) · `formal` (รายงาน เอกสารทางการ) ถ้าไม่ระบุ skill จะเดาจากเนื้อหาและบอกว่าเลือกระดับไหน

**กฎที่ไม่ละเมิด**

- ไม่เปลี่ยนข้อเท็จจริง ตัวเลข วันที่ ชื่อคน ชื่อแบรนด์ ราคา
- ไม่แตะคำพูดของคนอื่น ลิงก์ โค้ด ชื่อเฉพาะ
- ไม่เพิ่มข้อมูลที่ต้นฉบับไม่มี
- คงคำลงท้าย ครับ/ค่ะ ของผู้เขียน ไม่สลับเพศ
- ถ้าข้อความเป็นธรรมชาติอยู่แล้ว จะบอกตรงๆ และแก้น้อยที่สุด

## ติดตั้ง

### Claude.ai (อัปโหลด zip)

1. ดาวน์โหลด `humanizer-th.zip` จากหน้า [Releases](https://github.com/inatbalthazar/Thai-Humanizer/releases) (หรือสร้างเองด้วย `scripts/build_zip.sh`)
2. เปิด Settings → Capabilities → Skills แล้วอัปโหลดไฟล์ zip
3. เปิดใช้ skill แล้วเริ่มคุยได้เลย

### Claude Code

คัดลอกโฟลเดอร์ skill ไปไว้ที่ `~/.claude/skills/`

```bash
git clone https://github.com/inatbalthazar/Thai-Humanizer.git
cp -r Thai-Humanizer/skills/humanizer-th ~/.claude/skills/
```

## วิธีใช้

วางข้อความไทยพร้อมคำสั่ง ตัวอย่าง

```text
ช่วยเขียนใหม่ให้เป็นธรรมชาติ ระดับ casual จะโพสต์เฟซบุ๊ก
[วางข้อความ]
```

```text
ตรวจข้อความนี้ว่าตรงไหนดูเป็น AI
[วางข้อความ]
```

```text
แก้แค่จุดที่แข็งๆ พอ อย่าเปลี่ยนโครงสร้าง ส่งอีเมลหาลูกค้า
[วางข้อความ]
```

ผลลัพธ์ในโหมด `rewrite` มีหน้าตาแบบนี้

```text
[ข้อความที่แก้แล้ว]

---
ระดับภาษา: professional
สิ่งที่เปลี่ยน:
- ตัด "ได้ทำการ" (TH03) 2 จุด
- เปลี่ยนประโยคแปลตรง "ทำให้แน่ใจว่า" เป็น "ตรวจให้ดีว่า" (TH07)
```

## รูปแบบที่ตรวจ (28 รูปแบบ)

| หมวด | รหัส | ตัวอย่าง |
|---|---|---|
| ประโยค | TH03 04 05 07 08 23 25 | "ได้ทำการ" "ถูกพัฒนาโดย" "ซึ่ง...ซึ่ง..." สำนวนแปลตรง "ไม่ใช่แค่... แต่คือ..." |
| คำ | TH02 09 10 19 20 21 22 24 | "ทำการตรวจสอบ" "ยกระดับ" "อย่างมีประสิทธิภาพ" "สามารถ...ได้" |
| น้ำเสียงและระดับภาษา | TH14 15 16 26 | "คุณ" ถี่ คำลงท้ายสลับเพศ ภาษาราชการใน LINE |
| โครงสร้างและรูปแบบ | TH01 06 11 12 13 17 | "ในยุคดิจิทัลปัจจุบัน" คำเชื่อมทุกประโยค ปิดท้ายสรุปซ้ำ |
| การเว้นวรรคและเครื่องหมาย | TH18 27 28 | จุลภาคแบบอังกฤษ จุดท้ายประโยค ขีดยาว |

รายละเอียด คำอธิบาย และกรณีที่ **ไม่ต้องแก้** ของแต่ละรูปแบบอยู่ใน [patterns.md](skills/humanizer-th/references/patterns.md) ส่วนระดับภาษากับคำลงท้ายอยู่ใน [registers.md](skills/humanizer-th/references/registers.md) และตารางคำแทนอยู่ใน [word-swaps.md](skills/humanizer-th/references/word-swaps.md)

## สิ่งที่ skill นี้ไม่ใช่

**skill นี้มีไว้ปรับภาษาให้อ่านง่าย ไม่ใช่เครื่องมือหลบ AI detector** ไม่ได้ออกแบบมาเพื่อหลบการตรวจจับ และจะไม่จงใจใส่คำผิดหรือไวยากรณ์ผิดเพื่อให้ดูเป็นคนเขียน

นอกจากนี้ยังไม่ใช่ตัวแปลภาษา (อังกฤษ → ไทย เป็นงานอื่น)

## ข้อจำกัด

- ใช้กับข้อความภาษาไทยเท่านั้น
- เป็นแนวทางที่ Claude อ่านแล้วทำตาม ไม่ใช่โปรแกรมที่ให้ผลเหมือนกันทุกครั้ง ผลลัพธ์ควรอ่านทวนก่อนใช้งานจริง
- การตัดสินว่าอะไร "ธรรมชาติ" ขึ้นกับผู้เขียนและผู้อ่าน รูปแบบบางอย่างเป็นเรื่องรสนิยม จึงมีกรณียกเว้นกำกับทุกรูปแบบ
- ยังไม่มีชุดทดสอบอัตโนมัติ (ดูแผนต่อไปใน [CHANGELOG](CHANGELOG.md))
