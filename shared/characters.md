# ตัวละคร สรรพนาม และคำลงท้ายในบทพูด

ใช้กับทุกงานที่มีคนพูด ทั้งซับไตเติล บทเกม และบทละคร

ภาษาอังกฤษมี I กับ you แบบเดียวใช้กับทุกคน แต่ภาษาไทยต้องเลือกสรรพนามตามว่าใครพูดกับใคร อายุห่างกันแค่ไหน สนิทกันแค่ไหน และกำลังอารมณ์ไหน เลือกผิดคนดูรู้ทันทีว่าเป็นงานแปลหรือเป็นบทที่ AI เขียน

## 1. หลักการ

1. **ตัดสินเป็นคู่** ไม่ใช่ทีละตัว ตัวละคร A อาจเรียกตัวเองว่า "ผม" กับหัวหน้า แต่ "กู" กับเพื่อน
2. **ใช้ให้ตรงกันตลอดเรื่อง** เปลี่ยนได้เมื่อความสัมพันธ์ในเรื่องเปลี่ยนจริง เช่น เริ่มสนิทกัน เลิกกัน หรือทะเลาะหนัก และให้เปลี่ยนตรงฉากนั้น ไม่ใช่สลับไปมา
3. **ละประธานได้เมื่อรู้อยู่แล้วว่าใครพูดกับใคร** คนไทยพูดจริงไม่ได้ใส่ "ฉัน" "คุณ" ทุกประโยค
4. **ห้ามเดาเพศจากชื่ออย่างเดียว** ดูจาก he/she ในต้นฉบับ ฉากที่เห็น หรือข้อมูลที่ผู้ใช้ให้ ถ้ายังไม่รู้และสำคัญต่อคำลงท้าย ให้ถาม
5. **ตัวละครที่มีวิธีพูดเฉพาะตัว** ให้ใช้ตามตัวละครนั้น เช่น ตัวละครชายที่ใช้ "ค่ะ" ในต้นฉบับ หรือตัวละครที่พูดห้วนตลอด ไม่ต้องปรับให้เป็นแบบทั่วไป

## 2. สรรพนามตามความสัมพันธ์

| ความสัมพันธ์ | แทนตัวเอง | เรียกอีกฝ่าย | หมายเหตุ |
|---|---|---|---|
| เพื่อนสนิทผู้ชาย | กู / เรา / ชื่อเล่น | มึง / นาย / แก / ชื่อเล่น | กู/มึง ฟังสนิทแต่หยาบ ใช้ตามเรตของเรื่อง |
| เพื่อนสนิทผู้หญิง | ฉัน / เรา / ชื่อเล่น | แก / เธอ / ชื่อเล่น | |
| เพื่อนต่างเพศ | เรา / ฉัน / ผม | นาย / เธอ / แก / ชื่อเล่น | |
| คู่รัก | เค้า / ผม / ฉัน / พี่ / ชื่อเล่น | ตัวเอง / คุณ / เธอ / น้อง / ชื่อเล่น | คนอายุมากกว่ามักเป็น "พี่" |
| พี่กับน้อง (ครอบครัว) | พี่ / ชื่อเล่น | น้อง / ชื่อน้อง / แก | น้องเรียกพี่ว่า "พี่" หรือ "พี่ + ชื่อ" |
| พ่อแม่กับลูก | พ่อ / แม่ | ลูก / ชื่อเล่น | ลูกแทนตัวว่า หนู / ผม / ชื่อเล่น |
| หัวหน้ากับลูกน้อง | ผม / ฉัน / พี่ | คุณ / ชื่อ / น้อง | ที่ทำงานไทยหลายแห่งใช้ "พี่" กับ "น้อง" |
| ลูกน้องกับหัวหน้า | ผม / ฉัน / ดิฉัน / หนู | คุณ + ชื่อ / พี่ / หัวหน้า / ตำแหน่ง | "ดิฉัน" ใช้ในที่ทางการมาก |
| คนแปลกหน้าวัยใกล้กัน | ผม / ฉัน | คุณ | |
| คนแปลกหน้าต่างวัย | ผม / หนู / ฉัน | พี่ / น้อง / ป้า / ลุง / น้า | คนไทยเรียกคนแปลกหน้าด้วยคำเรียกญาติตามอายุ |
| พนักงานกับลูกค้า | ผม / ดิฉัน / ละประธาน | คุณลูกค้า / ลูกค้า / คุณ | |
| ศัตรู ทะเลาะกัน | กู / ฉัน / ข้า | มึง / แก / เอ็ง | |
| เด็กเล็ก | หนู / ชื่อเล่น | ตามคำเรียกญาติ | |

## 3. ย้อนยุค แฟนตาซี และไซไฟ

| แนว | แทนตัวเอง | เรียกอีกฝ่าย | คำลงท้าย |
|---|---|---|---|
| แฟนตาซียุคกลาง กำลังภายใน | ข้า | เจ้า / ท่าน (คนที่เคารพ) | ขอรับ / เจ้าค่ะ / เถิด |
| ราชสำนัก | กระหม่อม / หม่อมฉัน (พูดกับเจ้านาย) | ฝ่าบาท / องค์ชาย / องค์หญิง | พ่ะย่ะค่ะ / เพคะ |
| สำนักวิทยายุทธ | ข้า / ศิษย์ | ท่านอาจารย์ / ศิษย์พี่ / ศิษย์น้อง | |
| ทหาร ตำรวจ | ผม / กระผม (กับผู้บังคับบัญชา) | ท่าน / ยศ + ชื่อ | ครับผม |
| หุ่นยนต์ AI ในเรื่อง | ละประธาน / ระบบ / ดิฉัน | ผู้ใช้ / คุณ / ชื่อ | ตามบุคลิกที่ตั้งไว้ |

ราชาศัพท์ในราชสำนักแฟนตาซี ใช้พอให้ได้บรรยากาศ ไม่ต้องครบตามธรรมเนียมจริงทุกคำ แต่คำที่ใช้ต้องใช้ถูก เช่น "เพคะ" ผู้หญิงพูด "พ่ะย่ะค่ะ" ผู้ชายพูด

## 4. คำลงท้ายในบทพูด

| คำ | ความรู้สึก | ตัวอย่าง |
|---|---|---|
| ครับ / ค่ะ | สุภาพ | ได้ครับ |
| คะ | คำถาม หรือต่อท้าย "นะ" | ไปไหนคะ / ขอบคุณนะคะ |
| จ้ะ / จ้า | อ่อนโยน เป็นกันเอง ผู้ใหญ่พูดกับเด็ก | มาแล้วจ้ะ |
| นะ | อ้อนวอน ยืนยันเบาๆ | อย่าไปนะ |
| น่ะ | อธิบาย ตอบแบบเลี่ยงๆ | ก็ยุ่งน่ะ |
| สิ / ซิ | เร่ง ท้า ชวน | พูดมาสิ |
| เถอะ | ชวน ยอมแพ้ | กลับบ้านเถอะ |
| ล่ะ | ถามต่อ เปลี่ยนเรื่อง | แล้วนายล่ะ |
| หรอก | ปฏิเสธเบาลง | ไม่เป็นไรหรอก |
| วะ / ว่ะ / เว้ย | กันเองมาก หยาบ ผู้ชายมักใช้ | เอาจริงดิวะ |
| ฮะ / คร้าบ | ครับแบบเล่นๆ ทะเล้น | ได้คร้าบ |

**สะกดให้ถูก:** "นะคะ" ไม่ใช่ "นะค่ะ" ใช้ "คะ" กับคำถามและหลัง "นะ" ใช้ "ค่ะ" กับประโยคบอกเล่า

**อย่าใส่ทุกประโยค** คำลงท้ายสุภาพทุกบรรทัดทำให้บทพูดฟังเหมือนพนักงานคอลเซ็นเตอร์ ใส่ตรงที่ตัวละครต้องการแสดงความสุภาพ อ่อนโยน หรืออารมณ์

## 5. อารมณ์เปลี่ยน สรรพนามเปลี่ยน

คนไทยเปลี่ยนสรรพนามตามอารมณ์ ใช้เป็นเครื่องมือเล่าเรื่องได้

- โกรธจัด: "ผม/คุณ" กลายเป็น "ฉัน/แก" หรือ "กู/มึง"
- ประชด: สุภาพเกินเหตุ เช่น ใส่ "ครับ" ทุกคำ หรือเรียก "คุณ" กับเพื่อนสนิท
- เริ่มสนิท: จาก "คุณ" เป็นชื่อเล่น หรือ "พี่/น้อง"
- ห่างเหิน: จากชื่อเล่นกลับไปเป็น "คุณ"

เมื่อใช้แบบนี้ ให้จดในบันทึกว่าเปลี่ยนตรงไหนเพราะอะไร

## 6. คำเรียกชื่อ

- คนไทยเรียกชื่อเล่นมากกว่าชื่อจริง และเรียกด้วยคำเรียกญาติ (พี่ น้อง ป้า ลุง น้า อา ยาย ตา)
- ชื่อฝรั่งในเรื่องที่ตั้งในต่างประเทศ คงชื่อเดิม แต่คำเรียกเปลี่ยนตามไทยได้ เช่น "Mr. Carter" เป็น "คุณคาร์เตอร์" และ "Sir" เป็น "ท่าน" หรือละไป
- อย่าเรียกชื่อในทุกประโยค บทอังกฤษใส่ชื่อบ่อยกว่าที่คนไทยพูดจริง

## 7. ตารางตัวละคร

ทำก่อนแปลหรือเขียนบท และใช้ตารางเดียวกันทั้งเรื่อง

| ตัวละคร | เพศ อายุ | แทนตัวเอง | เรียกใคร ว่าอะไร | คำลงท้าย | วิธีพูด |
|---|---|---|---|---|---|
| มายา | หญิง 28 | ฉัน (กับเจค) / หนู (กับแม่) | เจค = นาย / แม่ = แม่ | ค่ะ เฉพาะกับผู้ใหญ่ | พูดเร็ว ประชดเก่ง |
| เจค | ชาย 30 | ผม | มายา = คุณ แล้วเปลี่ยนเป็น มายา หลังตอน 3 | ครับ น้อยๆ | สุภาพ พูดน้อย |
